## 책 구조
- 2단 구성, 문항 번호는 **Futura-Condensed 20pt 초록**, 번호 아래 **난이도 점 3개**(주황 칠해진 개수 = 하1·중2·상3, 0개도 하)
- 유형 머리('유형 10 다항식의 나눗셈')가 다음 유형까지 이어진다 → 문항의 유형은 직전 유형 머리
- **번호가 중단원마다 1번부터 다시 시작** → 이름은 학원 소단원 + 단원 안 순번(`01001`)

## 주의점
- 빠른 정답 표의 번호는 **DIN-Bold 9.3pt**, 자세한 해설 번호는 10.1pt — 크기로 가른다
- 표의 한 줄에 행렬 답이 있으면 다른 칸 번호의 y가 어긋난다 → **9pt 이내면 같은 줄**로 묶어야 순서가 안 꼬인다
- 해설 순서와 문제 순서는 **중단원 순번 + 번호**로 맞춘다(그냥 순서대로 짝지으면 어긋남)
- √·분수가 글자가 아니라 **그림**으로 들어간 답이 있다 → 숫자 정답 225개를 전부 눈으로 확인하고 3개(√10, 3/7, 1/6)를 자기채점으로 고침
- 레벨: 난이도 점 1개 2 · 2개 3 · 3개 4 (풍산자 필수유형과 같은 기준)
