# 쎈 시리즈 PDF → 문항 이미지 자르기 (공통수학1에서 처음 씀, 2026-09-18)

스캔본 PDF(한 쪽 = 사진 한 장)에서 문항·정답을 잘라 `upload-problems.mjs`용 데이터를 만든다.
**작업용 복사본이다.** 교재마다 조금씩 손봐야 하는 부분(아래 ⚠)이 있으니, 그대로 돌리지 말고
단계마다 결과 그림을 눈으로 확인하면서 진행할 것.

준비: Python 3.12 + `pip install pymupdf pillow numpy scipy`. 작업 폴더에 PDF를 복사해 둔다
(`q.pdf` = 문제, `quick_ssen.pdf` = 빠른정답). 스크립트는 그 폴더에서 실행한다.

## 핵심 아이디어
- **빠른정답이 기준**이다. 정답표의 번호 색(빨강 A / 초록 B / 파랑 C)으로 단계와 전체 번호 목록을 얻고,
  문제 PDF에서 찾은 번호를 그 목록과 순서대로 맞춘다 → 빠진 번호가 0이 될 때까지 확인.
- 번호 읽기는 tesseract가 아니라 **01단원에서 눈으로 확인한 번호 모양으로 만든 글자 틀**(`digits.py`)로 한다.
- 이미지 형식은 기존 쎈과 같다: 가로 680px, 위 44px 띠에 번호 → 인쇄 화면의 37px crop 그대로 동작.

## 순서
| 단계 | 스크립트 | 하는 일 |
|---|---|---|
| 1 | `qdet2.py 45 3 11` | 빠른정답에서 번호 라벨 찾기·읽기 → `qfinal.json`(번호·단계·단원) |
| 2 | `scan_all.py`, `scan2.py` | 문제 PDF 전체에서 번호·대표문제 상자·지시문([0003~0004])·유형 배지 찾기 |
| 3 | `align.py` | 문제 쪽 번호를 빠른정답 번호표와 맞추기 → `ordered.json` |
| 4 | `build_all.py` | 문항 이미지 자르기(묶음 지시문 붙이기, 그림 포함, 옆줄 문항 분리) + 빈틈 검사 |
| 5 | `answers_all.py` | 정답 이미지 자르기 (분수·행렬·연립 괄호 포함) |
| 6 | `ansread.py` → `choice2.py` | ①~⑤ 정답 읽기. **새로 찾은 것·애매한 것은 반드시 눈으로 확인** |
| 7 | `cref.py` | C단계의 "○쪽 유형 □□" 읽기. 범위 밖 값은 눈으로 보고 손으로 고침 |
| 8 | `final.py` | 난이도(하/중/상/대표)·서술형·레벨·유형·정답을 합쳐 `rows.json` |
| 9 | `atypes.py` | A단계 유형(책에 표시 없음 → 문제 보고 사람이 정한 범위표) |
| 확인 | `sheets_all.py`, `sheet2.py` | 단원별 모아보기 그림 |

## ⚠ 교재마다 다시 봐야 하는 것
- `detect.py`의 색 범위(H값), 번호 크기(`classify`) — 교재 인쇄 색이 다르면 조정
- `build_all.py`의 `OVR` — 번호가 뭉개져 못 읽은 지시문 끝번호를 손으로 넣은 것 (공수1 전용)
- `cref.py`의 `FIX`, `choice2` 결과의 수정(0635) — 공수1 전용 수정값
- `atypes.py`의 범위표 — 공수1 전용. 새 교재는 A단계 문제를 보고 새로 만든다
- 경로·`CH`(단원 번호)·`TITLES`·`TC`(단원별 유형 수) — `standard_types`에서 다시 뽑는다
- 숫자 정답은 OCR이 믿을 수 없어서 자동채점으로 넣지 않는다 (① ~ ⑤만 choice)
