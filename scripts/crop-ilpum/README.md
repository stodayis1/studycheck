# 일품(고난도 문제집) 한글→PDF → 문제은행 (중1(하), 2026-10-15)

RPM 한글판과 같은 제작사 판형(728×1031, 2단)이라 흐름은 `scripts/crop-rpm` 과 같지만 표시가 다르다.

```
python scripts/crop-ilpum/extract.py "<대단원.pdf>" <폴더>   # 구조 → items.json · marks.json
python scripts/crop-ilpum/crop.py    "<대단원.pdf>" <폴더>   # 자르기 → q/ a/ s/ · crop.json
python scripts/crop-ilpum/build.py   <자른폴더상위> <쌓을폴더>
node   scripts/upload-problems.mjs "<쌓을폴더>" scripts/problems_ilpum_m1_2.json
node   scripts/crop-solutions/upload.mjs "<쌓을폴더>/_해설" 일품 중1 2 --write
```

## 지면 읽는 법
| 무엇 | 어떻게 알아보나 |
|---|---|
| 문제 번호 | `HYwulB` 14pt. 「16 16.…」 처럼 글과 한 줄일 때도, 「1」 처럼 번호만일 때도 있다 |
| 소단원 | 쪽 머리말 「11-다각형」 (`HYwulM`/`HYsupB` 20pt) |
| 개념 & 핵심 기출 | 「개념 01」 상자 머리말 (`HYwulB` 12pt) |
| 만점 도전 고난도 | 「개념 01」 은띠 배너 (`ExpoM-HM` 12pt) — 같은 개념 번호를 **다시** 쓴다 |
| 대단원마무리 | `[Level 1]` / `[Level 2]`, 뒤쪽은 「교과서 속 창의유형」 |
| 정답·해설 | 「1. 답 ③」 + 그 아래 「[해설]」 |

## 걸려 넘어졌던 것
- **개념 상자의 제목이 틀려 있다.** 「개념 05 점, 선, 면」인데 내용은 맞꼭지각이다.
  그래서 유형 분류는 제목이 아니라 **상자 안 내용**을 읽고 `conceptmap.json` 에 손으로 적었다.
- **「유형 1,」 딱지가 번호로 보인다.** 「유형」은 그림이라 글자로는 `1.` 만 남는다 →
  `\d{1,2}\.` 만 딱 맞으면 번호가 아니라 창의유형 구역 딱지로 본다.
- **해설 쪽은 본문이 더 아래까지 내려온다.** 문제 쪽은 아래 분홍 줄(y≈940) 때문에 938 에서 끊어야 하지만,
  해설 쪽을 똑같이 끊으면 y 940~963 에 있는 답 6개를 놓친다 → `BOT_ANS = 972`.
- 대단원마무리는 번호가 1부터 다시 시작한다 → 번호 앞에 **M** 을 붙여 본문과 안 겹치게 했다.

## 쪽 번호가 없다
이 책은 한글 작업본만 있고 시중교재 스캔본이 없어서 `page_no` 를 비워 두었다.
스캔본이 생기면 번호(local_no)로 이어 붙여 쪽을 채우면 된다 — [[scan-vs-hwp-same-book]] 규칙 참고.
