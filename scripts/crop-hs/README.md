# 「핵심정리 및 유형별 단계별 교재」(JYJ 수학교실 판) → 문제은행 (중1-2, 2026-10-22)

```
python scripts/crop-hs/extract.py "<교재.pdf>" <폴더>   # 구조+빠른정답+글 → items/marks/answers/texts.json
python scripts/crop-hs/crop.py    "<교재.pdf>" <폴더>   # 자르기 → q/ a/ s/ · crop.json
python scripts/crop-hs/build.py   <자른폴더상위> <쌓을폴더>
node   scripts/upload-problems.mjs "<쌓을폴더>" scripts/problems_core_m1_2.json
node   scripts/crop-solutions/upload.mjs "<쌓을폴더>/_해설" 핵심유형 중1 2 --write
```

## 대단원마다 세 구간
| 구간 | 유형 표시 | 쓰나 |
|---|---|---|
| NN-1 핵심정리 및 예제 | 「개념」 머리말(HYtbrB 12pt) | ○ |
| NN-2 유형별 문제 | 「유형 01」 배지(HYwulM 14pt 흰 글자) + 제목(HYsupM 12pt) | ○ |
| NN-3 단계별 문제 (기초/기본/심화) | **없음** | ✗ — 단계 배지가 처음 나오면 거기서 멈춘다 |

## 걸려 넘어졌던 것
- **유형 배지 글자가 10번부터 「010」 「018」 꼴**이다. 배지 그림의 0 과 번호가 붙어 나온다.
  `\d{1,2}` 로만 보면 유형 10번 이후를 통째로 놓치고, 앞 유형이 수십 문항을 떠안는다.
  → `0(\d{1,2})` 로 읽는다.
- 문제 번호는 **검정** 16pt다 (기출단계별 교재는 남색이었다).
- 빠른정답 쪽과 해설 쪽이 둘 다 「N.」 11.5pt 로 시작한다.
  번호가 **25개 넘게 빽빽한 쪽**을 빠른정답으로 보고 건너뛴 뒤, 그 다음부터를 해설로 쓴다.

## 「심화 문제」·「서술형 문제」 묶음
한 묶음에 여러 유형이 섞여 있어 제목만으로는 못 가른다.
`keywords.json` 에 묶음별 낱말 규칙을 두고 **문제 글 + 풀이 글**에 걸어 한 문항씩 가른다.
214문항 중 133개가 이 규칙으로 더 잘게 갈렸고, 나머지는 그 묶음의 기본 유형을 쓴다.

## 난이도를 나눈 이유
원장님 말씀대로 **쌍둥이·유사문항을 레벨별로** 뽑으려는 것이다.
`app/api/reprint` 의 유사문항은 **같은 type_code + 같은 difficulty** 를 먼저 찾는다.
그래서 예제→하, 유형별→중, 심화·서술형→상 으로 갈라 두었다.
