## 함정 (겪은 것)

- **정답 짝짓기**는 「같은 칸에서 바로 위의 번호」로 하면 67문항을 놓친다(칸·쪽을 넘어감).
  번호와 「정답_」 줄을 **읽기 순서로 늘어놓고** 번호 다음에 처음 나오는 정답을 쓴다 → 985/985.
- **정답 그림**은 그 줄 전체를 자른다. 오른쪽으로 더 열면 옆 칸 풀이가 딸려 오고,
  「정답_」 만큼 왼쪽을 자르면 답의 첫 글자가 날아간다.
- **고득점·서술형 191문항은 책에 유형 번호가 없다.** 공수1 때는 손으로 190개를 정했는데,
  공수2는 글자가 있어 **같은 단원 유형 문항과 본문을 견주어** 자동으로 붙였다(163개).
  확신 낮은 28개만 본문을 읽고 직접 정했다 — 그중 19개가 바뀌었으니 꼭 볼 것.
- `json.dump(open(...,'w'))` 는 Windows 에서 cp949 로 써서 깨진다 → `io.open(..., encoding='utf8')`.
