## 어떻게 하나

```
# 1) 이 해설집 글꼴로 숫자 본보기 만들기 (교재 글꼴로 읽으면 0을 9로 읽는다)
python scripts/crop-solutions/digits.py "<해설집.pdf>" <작업폴더> --collect --k 40
#    → 작업폴더/clusters.png 를 보고 묶음마다 이름을 적는다 (쓰레기 묶음은 '-')
python scripts/crop-solutions/digits.py x <작업폴더> --label "7,2,3,9,0,5,..."

# 2) 풀이 자르기
python scripts/crop-solutions/crop.py "<해설집.pdf>" <나갈폴더> --digits <작업폴더>
python scripts/crop-solutions/crop.py "<해설집.pdf>" <나갈폴더> --digits <작업폴더> --dry   # 검출만 확인
```

원리
1. 쪽을 2단으로 나눈다
2. 단 왼쪽 끝의 **색 글자 4자리**(번호)를 찾는다. 번호 색은 단원마다 다르다(연두·파랑…)
3. 숫자 본보기로 번호를 읽고, **오름차순으로 이어지는 가장 긴 줄기**만 믿는다
   (잘못 잡힌 것·잘못 읽은 것이 여기서 걸러진다 → 엉뚱한 풀이가 붙는 사고를 막는다)
4. 번호 줄부터 다음 번호 줄까지 잘라 낸다. 단 끝에서 넘어가면 다음 단 조각을 이어 붙인다
