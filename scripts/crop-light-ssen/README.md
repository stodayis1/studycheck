## 2026-09-21 추가 — 정답집이 문제집과 **다른 판**임을 확인
원장님이 주신 `라이트쎈 중1-1.pdf`(정답 및 풀이, 104쪽)로 다시 시도했다.
- 해설의 "답" 표시는 **1,345개**를 정확히 찾았다(`answer_markers.json`, 템플릿 매칭 0.72 이상). 자르기도 된다.
- 그런데 **번호가 문제집과 어긋난다**:
  - 해설 `0100` = "10×48의 약수의 개수" → 문제집에서는 **0102**
  - 해설 `0209` = "소인수 지수 a×b−c=10" → 문제집 `0209`는 "42, 48의 최소공배수"(답 ③)인데 해설·빠른정답은 모두 ⑤
  - 0001~0060 구간은 일치 → 같은 시리즈지만 **개정판에서 문항이 몇 개 추가**되어 뒤로 갈수록 밀린다
- 즉 문제집은 **(개정) 라이트쎈**, 정답집 2개는 **개정 전 판**이다. 그대로 붙이면 자동채점이 틀린다 → 올리지 않음.
