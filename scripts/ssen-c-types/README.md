# 중등 쎈 C단계(최고수준) 유형 붙이기 — 2026-09-21

2026-09-15에 올린 중등 쎈 1·2·3학년의 **C단계 1,108문항에 유형이 없어서 문제은행 화면에 안 보이던 것**을 고친 작업.

## 어디서 유형을 읽었나
중등 쎈 C단계 문항 이미지에는 오른쪽 위에 **"11쪽 · 유형 01"** 이 인쇄돼 있다(중3은 "· 12쪽 유형 01 + 유형 02" 꼴).
PDF가 없고 이미 잘린 이미지만 있어서, 이 머리말 띠를 모아 **눈으로 읽었다**(초록 숫자 자동 인식은 붙은 글자·스캔 흐림 때문에 실패).

| 파일 | 하는 일 |
|---|---|
| `locate.py` | DB의 유형 없는 문항 ↔ `C:\Users\USER\문제은행\<학년-학기>\...\쎈\<소단원>\<번호>.png` 짝 맞추기 |
| `seg.py` | 머리말에서 초록 숫자 영역 찾기(검토용) |
| `sheets.py` | 머리말 띠 50개씩 모은 검토 시트 23장 생성 |
| `readings.txt` | 시트를 읽어 적은 결과 (`11c01 104=1 105=3 …` = 중1-1 소단원01 104번 → 유형 1) |
| `final.py` | 읽은 값 검증(그 소단원에 있는 유형인지) → `update.json` |

## 규칙
- 유형이 둘 이상 적힌 문항(`유형 05 | 유형 12`)은 **첫 번째**를 쓴다 — 공수1 쎈(`crop-ssen/final.py`)과 같은 규칙
- 책 유형 번호 = 학원 `standard_types` 번호. **예외 하나**: 중3-1 소단원 12는 학원 유형표가 12·13으로 쪼개져 있어 책 유형 10~13 → `중3-1-13-01~04`
- 머리말이 안 보이는 문항(묶음 문제의 두 번째, 표·그래프가 먼저 나오는 문항)은 원본을 직접 보고 손으로 적음
- 레벨·난이도는 건드리지 않음 (C단계는 원래 레벨 4, 난이도 없음 — 공수1 쎈 C와 같은 모양)
