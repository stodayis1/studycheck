## 왜 못 올리나
정답 두 파일 모두 문제집과 **판이 다르다.** 번호는 거의 같은데 **군데군데 문항이 바뀌어 있다.**
내용으로 대조한 20문항 중 3개가 어긋났다(15%). 자기채점에 쓰기엔 너무 위험하다.

| 번호 | 문제집 | 정답 파일 |
|---|---|---|
| 0046 | AD의 길이를 구하시오 (답 5 cm) | ① |
| 0299 | FE의 길이를 구하시오 (답 14 cm) | 50°  ← 14 cm는 정답 파일의 **0300** |
| 0426 | ∠AEB의 크기를 구하시오 (답 60°) | 4 cm |

구조도 어긋난다
- 문제집 ch05 B단계 시작 **0458** ↔ 정답 파일 **0459**
- 문제집 ch06 A단계 끝 **0541** ↔ 정답 파일 **0539**
- 문제집 ch06 학교시험 끝 **0601** ↔ 정답 파일 **0595** (정답 파일은 0596부터 ch07)
- 문제집 마지막 번호 **1102**, 정답 파일 **1099**

### 처음에 속을 뻔한 점 (다음에 되풀이하지 말 것)
번호마다 단계 색(A 주황 · B 초록 · 학교시험 파랑)을 전수 대조했더니 **0001~0457 불일치 0건**이 나왔다.
그래서 "앞부분은 맞다"고 판단했는데 **틀렸다.** 단계 대조는 *단계 경계를 넘는* 어긋남만 잡는다.
긴 학교시험 구간 안에서 문항이 바뀌거나 하나 끼어들었다 빠지면 경계가 도로 맞아서 안 걸린다.
→ **판 확인은 반드시 '문제 내용 ↔ 정답 내용'으로, 구간마다 골고루** 해야 한다.
