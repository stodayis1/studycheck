# 풍산자 라이트유형 PDF → 문항 이미지 (공통수학1, 2026-09-19)

풍산자 필수유형(`scripts/crop-psj`)과 같은 글자 PDF. 차이점:
- 번호가 **단원마다 001부터 다시** 시작하고, 연습문제는 01~24 두 자리 → `local_no`는 `01001`(기본) / `01S03`(연습)
- 번호 폰트 Jalnan 14pt, 유형 머리 Jalnan 12pt 흰 글자, 정답은 `답` 표시 뒤 (정답 칸은 그 줄에 겹치는 글자·괄호·분수선만 모아서 자름)
- `b2s.py`: 책 유형 → 학원 유형(`B2S`), 개별 수정(`OVR`), 연습문제 유형(`EX`, 문제를 보고 정함)
- 레벨: 기본 2 · 연습 3 · UP 4 (원장님 결정)

## 공통수학2 (2026-10-22)

같은 파이프라인을 그대로 쓰되 세 군데를 손봤다.

| 무엇 | 공통수학1 | 공통수학2 |
|---|---|---|
| 번호 글꼴 | `Jalnan` | **`JalnanOTF`** → `startswith('Jalnan')` 로 둘 다 받게 고침 |
| 해설 번호 | 연습이 두 자리 | **연습도 세 자리** → 단원을 다시 추측하면 어긋난다 |
| json 저장 | — | 윈도에서 cp949 로 깨짐 → `io.open(..., encoding='utf8')` |

**해설의 번호 차례는 문제 차례와 똑같다(659=659 확인).** 그래서 ans.py 는 단원을 추측하지 않고
`q_meta.json` 의 차례에 그대로 맞춘다. 이 한 줄이 어긋난 정답 4개를 없앴다.

유형 대응은 `map_g2.json` — 책 유형 123가지 → 앱 유형코드. 유형 배지가 없는 연습문제 179개는
같은 파일의 낱말 규칙으로 가르고(106개 걸림), 안 걸리면 그 단원의 기본 유형을 쓴다.
레벨은 기본 2 · 연습 3 · UP 4 (원장님 기준에서 3 = 쎈 B단계).

실행:
```
python crop.py && python ans.py && python rows_g2.py <쌓을폴더>
node scripts/upload-problems.mjs <쌓을폴더> scripts/problems_psl_hc2.json
```
