# 풍산자 라이트유형 PDF → 문항 이미지 (공통수학1, 2026-09-19)

풍산자 필수유형(`scripts/crop-psj`)과 같은 글자 PDF. 차이점:
- 번호가 **단원마다 001부터 다시** 시작하고, 연습문제는 01~24 두 자리 → `local_no`는 `01001`(기본) / `01S03`(연습)
- 번호 폰트 Jalnan 14pt, 유형 머리 Jalnan 12pt 흰 글자, 정답은 `답` 표시 뒤 (정답 칸은 그 줄에 겹치는 글자·괄호·분수선만 모아서 자름)
- `b2s.py`: 책 유형 → 학원 유형(`B2S`), 개별 수정(`OVR`), 연습문제 유형(`EX`, 문제를 보고 정함)
- 레벨: 기본 2 · 연습 3 · UP 4 (원장님 결정)
