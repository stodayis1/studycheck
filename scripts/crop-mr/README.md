# 유형만렙(비상) PDF → 문항 이미지 (공통수학1, 2026-09-19)

글자 PDF. 문제: 학생용 본문, 정답: 정답과 해설(풀이 포함).
- `scan.py`: 번호(Hoyoyo 12.7pt, 색으로 구역: 초록 A / 파랑 B / 검정 유형점검 / 보라 C 실력향상), 유형 머리, 묶음 지시문 [0005~0007]
- `crop.py`: 번호와 지문이 같은 줄 → 번호 줄부터 자르고 번호 글자만 지움. 한 줄에 두 문항(1115 1116) 분리, 행렬처럼 번호 위로 솟은 식 포함
- `ans.py`: `답` 표시가 있는 줄만 잘라 풀이가 딸려 오지 않게 함. **숫자 정답은 줄 전체 글자로 확인** (√가 글자로 안 잡혀 10√13 → 1013이 되는 일이 있었음)
- `mtypes.py`: 책 유형 → 학원 유형(B2S), A단계 범위표(AR), 실력향상·태그 없는 점검 문항(MAN)
- 레벨: A 1 · B 하/중/대표 3, 상 4 · 유형점검 3 · C 실력향상 4 (원장님 결정)
