문제: 학생용 · 유형 번호: **교사용**(시험에 꼭 나오는 문제마다 "유형 NN") · 정답: 정답 PDF(해설 포함)
- `scan.py` 번호(MyriadPro-Bold 13pt, 색: 초록 교과서 / 청록 유형익히기 / 보라 발전 / 주황 시험에 꼭) → ev.json
- `crop.py` 자르기. 주의점
  - 학생용 PDF에 **보이지 않는 정답 글자**가 숨어 있다 → 배지 지우기는 배지 글자 목록으로만
  - 수식 글자 bbox가 실제보다 훨씬 크다 → 위로 솟은 식은 글자 bbox가 아니라 **잉크(픽셀)** 로 판단 (`inktop`)
  - 서술형/실력UP 제목은 글자가 아니라 색 띠(136×21pt) → 띠 색으로 구분
  - 워터마크 이메일, '중요' 별 배지(작은 도형) 지움
- `diff.py` 상/중/하는 글자 위 노란 반원 도형 위치로 읽음
- `ans.py` `답` 줄만 자름. 한 줄에 정답 여러 개(1002 1003)·행렬/연립(괄호 글꼴 BTparen) 처리. 괄호형·분수·근호 답은 자기채점
- `rtypes.py` 책 유형→학원 유형, 교과서 문제는 개념 번호(01-3 등)→대표 유형
- 레벨(원장님 확인 완료): 교과서 2 · 유형익히기 3(상 4) · 발전 4 · 시험에 꼭 3 · 서술형 3 · 실력UP 4

# RPM 중학수학 1-1 (한글→PDF 판, 2026-10-15)

같은 RPM 이지만 **한글로 다시 짜인 단원별 PDF 9개**라 위의 공통수학1 방식과 전혀 다르다.
글자층이 살아 있어 그림을 추측할 필요가 없고, 지면이 아주 규칙적이다.

```
python scripts/crop-rpm/extract.py "<단원.pdf>" <폴더>   # 구조 읽기 → items.json · marks.json
python scripts/crop-rpm/crop.py    "<단원.pdf>" <폴더>   # 자르기 → q/ a/ s/ · crop.json
python scripts/crop-rpm/build.py   <자른폴더상위> <쌓을폴더>   # 업로드용 데이터·폴더 만들기
node   scripts/crop-rpm/apply.mjs [--write]              # 이미 올라간 문항의 정보만 고치기
```

알아 둘 것
- **수식은 HWP 전용 글꼴(HyhwpEQ)** 이라 글자 코드가 사용자 영역(0xE000~)이다 → `eqfont.py` 로 푼다.
  푸는 건 유형 제목을 읽을 때만 쓰고, 문제·정답·해설은 **글자로 옮기지 않고 그림으로 자른다**.
- 번호는 책 전체를 통틀어 이어진다(1~1123). 네 자리까지 간다.
- 단원마다 **교과서 → 유형 익히기 → 시험에 꼭 → 서술형 주관식 → 실력 UP** 순이다.
  04단원처럼 「유형 익히기」 큰 제목이 아예 없는 곳이 있어, **유형 머리말이 처음 나오는 자리**를 구간 시작으로 삼는다.
- 교과서 구간의 짧은 문제는 「[0001~0006] 다음 …」 묶음 지시문에 매달려 있다.
  지시문은 **다른 단, 때로는 앞 쪽**에 있으니 문제 자리가 아니라 지시문 제 자리를 보고 잘라 위에 얹는다.
- 자를 때 **자가 점검**이 돈다 — 잘라낸 네모 안에 내 번호 하나만 있어야 하고, 지시문 자리엔 번호가 없어야 한다.
  `crop.json` 의 `bad` 가 비어 있지 않으면 눈으로 보기 전에 이미 틀린 것이다.
- 유형 → 앱 유형코드는 `typemap.json`(유형 162개), 교과서 구간은 `textbookmap.json`(지시문 기준),
  유형이 안 붙은 종합문제 215개는 `restmap.json` 에 하나씩 적어 두었다.

2026-10-02 에 올라가 있던 RPM 원본 교재 판(그림이 더 깔끔)과 **번호가 같아서**,
그림은 그대로 두고 `apply.mjs` 로 정보만 갈아끼웠다. 되돌리려면 `되돌리기.sql` 을 실행한다.
