# RPM(개념원리) PDF → 문항 이미지 (공통수학1, 2026-09-19)

문제: 학생용 · 유형 번호: **교사용**(시험에 꼭 나오는 문제마다 "유형 NN") · 정답: 정답 PDF(해설 포함)
- `scan.py` 번호(MyriadPro-Bold 13pt, 색: 초록 교과서 / 청록 유형익히기 / 보라 발전 / 주황 시험에 꼭) → ev.json
- `crop.py` 자르기. 주의점
  - 학생용 PDF에 **보이지 않는 정답 글자**가 숨어 있다 → 배지 지우기는 배지 글자 목록으로만
  - 수식 글자 bbox가 실제보다 훨씬 크다 → 위로 솟은 식은 글자 bbox가 아니라 **잉크(픽셀)** 로 판단 (`inktop`)
  - 서술형/실력UP 제목은 글자가 아니라 색 띠(136×21pt) → 띠 색으로 구분
  - 워터마크 이메일, '중요' 별 배지(작은 도형) 지움
- `diff.py` 상/중/하는 글자 위 노란 반원 도형 위치로 읽음
- `ans.py` `답` 줄만 자름. 한 줄에 정답 여러 개(1002 1003)·행렬/연립(괄호 글꼴 BTparen) 처리. 괄호형·분수·근호 답은 자기채점
- `rtypes.py` 책 유형→학원 유형, 교과서 문제는 개념 번호(01-3 등)→대표 유형
- 레벨(임시, 원장님 확인 전): 교과서 2 · 유형익히기 3(상 4) · 발전 4 · 시험에 꼭 3 · 서술형 3 · 실력UP 4
