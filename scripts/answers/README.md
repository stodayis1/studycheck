# 개념+유형(비상) 정답 글자 뽑기

답지 화면이 그림 대신 **글자**로 나오게 하려고, 해설 PDF에서 정답을 읽어 `answer_text`에 넣는다.
(글자 정답이 있으면 객관식·숫자는 자동 채점까지 된다)

| 파일 | 하는 일 |
|---|---|
| `ky_yh.py` | **유형편** — 해설 뒤쪽 유형편 구간의 **빠른 정답표**(DIN-Bold 9.3pt)에서 읽는다. 자세한 풀이(10.1pt)와는 글자 크기로 가른다 |
| `ky_gn.py` | **개념편 유제** — 번호가 `08-` + `2`로 쪼개져 있고, 정답은 바로 뒤 **굵은 글꼴**(NPBIE·NPRUTB)로 온다. 풀이는 다른 글꼴이라 글꼴로 가른다 |
| `apply.py` | 뽑은 정답을 problems에 넣는다. 한글 수식 표기를 바꾼다(`@`→², `#`→³, `$`→⁴, 백틱→공백) |

## 주의점

- **2단 구성이다.** y좌표만으로 정렬하면 좌·우 칸이 섞여 번호가 들쭉날쭉해진다 → `(쪽, 칸, y)` 순으로 정렬할 것
- **책의 중단원과 학원 소단원이 다르다.** 공통수학1 개념편은 책이 18번 번호를 리셋하는데 학원 소단원은 10개다.
  그래서 번호로 키를 만들면 안 맞는다 → **순서로 짝지었다**(해설 유제 수와 DB 유제 수가 315로 정확히 같은 것을 확인하고,
  이미 들어 있던 정답과 대조해 내용이 같은 것까지 확인한 뒤 적용)
- 예제(필수예제)는 **풀이 전체가 정답**이라 한 줄로 못 뽑는다. ∴ 줄만 모으면 쪽 머리말이 섞이거나 빈 줄이 된다.
  예제는 지금처럼 **풀이 상자 그림**을 쓴다.

## 쓰는 법

```
python scripts/answers/ky_yh.py "<정답과해설 PDF>" out.json <유형편 시작쪽-1>
python scripts/answers/ky_gn.py "<정답과해설 PDF>" out.json <개념편 끝쪽>
python scripts/answers/apply.py out.json "개념+유형 유형편" 공통수학2
```

## 글자 층이 없는 교재 — 이미 잘라 둔 정답 그림을 «두 번 따로» 읽는다 (2026-10-27, 라이트쎈 중1-2)

해설 PDF 가 스캔 그림이면 위 방법(글꼴로 가르기)을 못 쓴다. 대신 문항마다 이미 잘라 둔
정답 그림(`problem-images` 의 `*_a.png`)을 읽는다. ocr-check 스킬(`~/.claude/skills/ocr-check`)의 방식이다.

1. 정답 그림을 번호표와 함께 한 장에 30개씩 모은다 → **판독1**(Claude)
2. **25개씩·다른 배율**로 다시 모은 묶음을 **다른 세션**이 판독1 을 보지 않고 읽는다 → **판독2**
3. 객관식(①~⑤)·숫자만 엄격히 대조한다. 다른 곳은 원본을 크게 키워 정한다
4. 숫자는 tesseract 로 한 번 더 읽고, 다른 곳만 원본을 눈으로 본다(옆 그림 조각에 잘 끌린다)
5. **객관식·숫자만** 글자 정답으로 바꾼다. 단위가 붙은 답(8 cm · 70° · 20 %)·O/X·이름·식은 그림 그대로
   (채점은 공백·쉼표만 지우고 글자 그대로 비교해서, 단위가 붙으면 학생이 「8」 이라고 써도 틀린다)

|---|---|---|---|---|---|---|
| 라이트쎈 중1-2 | 645 | 180 | 57 | 408 | 0 | `라이트쎈_중1-2_정답.sql` (+ `_되돌리기`) |
