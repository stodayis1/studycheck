# 개념+유형 유형편 공통수학1 — 글자 정답이 남의 자리 값이다 (240문항)

2026-11-04, 「문제 ↔ 정답」 짝 점검(`정답짝_점검표.md`) 중에 찾았다.
**라이트쎈 중2-1 과는 다른 종류의 사고다** — 그림은 제자리고 **글자 정답만** 어긋났다.

## 무엇이 어긋났나

정답 그림 600장을 전부 다시 읽어 DB 와 맞대 보니 **236문항이 달랐다**(577개 중).

| 그림(다시 읽은 값) | 그 값이 DB 에 적혀 있던 자리 |
|---|---|
| 03007 `7+2i` | **04007** |
| 03024 `4i` | **04024** |
| 04003 `-14` | **06003** |
| 04021 `x²-3x+1=0` | **06021** |
| 05040 `20 m` | **08019** |
| 06052 `(-3,-1), (3,1)` | **10004** |

값이 **다음 단원 쪽 자리로 옮겨 적혀** 있다. 종류까지 어긋났다 —
`03009` 는 그림이 **②**(객관식)인데 DB 에는 `-3`(숫자)로 들어 있었다.

## 어디가 틀렸나 — 단원마다 **앞부분만**

| 단원 | 문항 | 틀림 | 틀린 구간 |
|---|---|---|---|
| 01 | 46 | 4 | 01004~01041 (식 표기뿐) |
| 02 | 80 | **0** | 전부 맞음 |
| 03 | 61 | 34 | 03002~03037 (뒤 03061까지 맞음) |
| 04 | 38 | 35 | 04002~04038 |
| 05 | 44 | 16 | 05001~05018 (뒤 05044까지 맞음) |
| 06 | 74 | 35 | 06001~06038 (뒤 06074까지 맞음) |
| 07 | 46 | 19 | 07001~07021 (뒤 07046까지 맞음) |
| 08 | 56 | 23 | 08001~08023 (뒤 08056까지 맞음) |
| 09 | 91 | 45 | 09001~09048 (뒤 09091까지 맞음) |
| 10 | 64 | 25 | 10001~10026 (뒤 10064까지 맞음) |

**단원마다 앞쪽 절반쯤이 밀리고 중간부터 제자리로 돌아온다.** 통째로 옮기는 식으로는 못 고친다.

## 문제·정답 그림은 제자리다 (그래서 고칠 수 있다)

8문항을 **직접 풀어** 그림과 맞대 봤다 — 전부 맞았다.

- `01001` A+B 간단히 → 2x²+2y² = **②** = 그림 ②
- `04034` x²-6x+a=0 의 한 근이 b-√2 → b=3, a=7, a+b=**10** = 그림 10 (DB 는 `①` 이었다)
- `06026` 삼차방정식 세 근 → 2(αβ+βγ+γα)/αβγ = -4/3 = **①** = 그림 ①
- `07027` 연속한 세 정수 → 가장 작은 수 **10** = 그림 10
- `09009` (a+b)(x+y+z)(p+q+r) 항의 개수 → 2·3·3 = **18** = 그림 18 (DB 는 `②` 였다)

→ **그림을 다시 읽으면 바른 답이 나온다.**

**판독은 두 번 했다.** 1차와 2차가 다른 곳은 `03061`(④→**⑤**) 한 곳뿐이었고,
1차에 못 읽은 세 곳(`02042`·`04038`·`05021`)을 2차에서 채웠다.
2차는 1차와 **다른 배치**로 보아야 같은 실수를 두 번 하지 않는다.

## 고칠 SQL (아직 적용 안 함)

`docs/sql/개념유형유형편_공수1/글자정답_다시쓰기.sql` — **240문항**
- 객관식 113 · 숫자 100 · **글자 정답을 지우고 그림으로 되돌릴 것 27**

되돌릴 27개는 식·부등식·행렬·문장이다(`x≤-4 또는 x≥8`, `2x²+16`, 행렬 …).
**이런 것은 글자 정답으로 넣으면 안 된다** — 학생이 칠 수 없는 답인데다,
글자 정답이 있으면 서버가 정답 그림 주소를 아예 안 만들어 **맞춰 볼 것이 없어진다.**

되돌리기: `글자정답_되돌리기.sql`
