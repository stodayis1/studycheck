# 창고에 아예 없는 정답 그림 — 2026-10-27 에 257장, 2026-11-03 에 95장 채움 (남은 162장)

DB 의 `problems.answer_image_path` 에는 경로가 적혀 있는데 **창고(Storage)에 그 파일이 없다.**
학생이 QR 로 들어가면 그 문항은 「정답 없음」으로 뜬다. 에러도 안 나고 아무도 모른다.

`node scripts/answers/missing_images.mjs <나갈.json>` 으로 **38,298문항을 전수 점검**해 찾았다.

## 95장을 해설 PDF 에서 떠서 채웠다 (2026-11-03)

```
node scripts/answers/rpm_cut_answer.py "<해설 PDF>" <번호목록.json> <나갈폴더>
node scripts/answers/upload_answer_img.mjs RPM/중1/1 <나갈폴더> [--빼기 0900]
```

**글자로 옮기지 않고 지면을 그대로 떴다.** 해설의 수식은 글자 층에 `2Ü`_5Û``·`;2!;`·`'¶31` 같은
출판사 전용 글자로 들어 있어, 옮겨 적으면 한 글자만 틀려도 학생이 틀린 답을 본다.
그림으로 뜨면 옮겨 적는 일이 없으니 틀릴 일도 없다.

| 교재 | 뜬 것 | 뺀 것 |
|---|---|---|
| 중1-1 | 60 | 0900 (「34단계」 — 답 같지 않다) |
| 중1-2 | 3 | |
| 중2-1 | 21 | |
| 중3-1 | 11 | 0146 · 0860 · 0865 |

★ **중3-1 0860 은 뜬 그림이 `−5` 인데 실제 답은 61 이다**(책의 두 면 쪽수 곱이 930 = 30×31 → 합 61).
그 61 은 0865 자리에 떠 있었다. 그 구간은 해설 지면의 번호와 답이 엇갈려 있으니
**중3-1 의 남은 것을 채울 때는 한 문항씩 직접 풀어 확인할 것.**

남은 162장(중3-1 57 · 중1-1 45 · 중1-2 31 · 중2-1 29)은 번호와 「답」이
같은 단·같은 차례로 안 잡혀 못 떴다. 자르는 규칙을 더 손봐야 한다.

- **문제 그림은 하나도 안 빠졌다** — 인쇄되는 시험지는 멀쩡하다. 빠진 것은 정답 그림뿐이다.
- 257장 **모두 글자 정답도 없는 문항**이라, 지금은 학생이 맞춰 볼 것이 아무것도 없다.
- RPM 에만 몰려 있다. 단원별로는 `m1-1/rpm/02` 21장, `m1-1/rpm/04` 20장, `m2-1/rpm/09` 20장 … 로 흩어져 있어
  한 번에 실패한 것이 아니라 **올릴 때마다 조금씩 빠진** 모양이다.

## 고치는 두 가지 길

1. **정답 그림을 다시 잘라 올린다** (`scripts/crop-rpm/`). 그림 정답으로 남을 문항은 이 길뿐이다.
2. **글자 정답을 넣는다.** 글자 정답이 있으면 서버가 정답 그림 주소를 아예 안 만들기 때문에
   그림이 없어도 상관없다. RPM 중1-1 은 학원이 가진 **한글본 PDF**(단원별 .hwp/.pdf)에서
   객관식 답을 뽑아 17문항을 이 길로 메웠다 (`scripts/answers/rpm_hwp.py`).
   나머지는 한글본에서 숫자가 수식 개체라 글자 층에 안 남아 있어, 한글본 쪽수를 그림으로 떠서 읽어야 한다.
