# 개념+유형 개념편 공통수학1 — 글자 정답이 남의 자리 값이다 (181문항)

2026-11-04. 같은 출판사의 **유형편 공수1** 과 **같은 종류의 사고**다
(`개념유형유형편_공수1_글자정답_어긋남.md`). 문제도 정답 그림도 제자리이고 **글자 정답만** 어긋났다.

## 어긋난 꼴 — 값이 뒤 자리로 밀려 있다

한 칸에서 시작해 뒤로 갈수록 벌어진다. **통째로 옮기는 식으로는 못 고친다.**

## 그림이 맞다 — 직접 풀어 확인했다

- `0201S1` 등식 (k−2)x+(3−k)y+2k−3=0 이 k 에 관계없이 성립
  → k(x−y+2) + (−2x+3y−3) = 0 → **x=−3, y=−1** = 그림. (DB 는 「몫: x²+3x+1」이었다)
- `0204S1` x³−3x²−4x+1 = a(x+1)³+b(x+1)²+c(x+1)+d
  → a=1, b=−6, c=5, d=1 → abcd = **−30** = 그림. (DB 는 `a=-1, b=3` 이었다)
- `0206S3` (x−2)f(x)÷(x+2) 나머지 4, (3x−1)f(x)÷(x−2) 나머지 15
  → f(−2)=−1, f(2)=3 → f(x)÷(x²−4) 나머지 **x+1** = 그림. (DB 는 `1` 이었다)

## 이 교재는 답이 대부분 **식·문장**이다

서술형 교재다(번호가 `0201S1` 처럼 S 로 끝난다). 글자 정답으로 넣을 수 있는 것은 순수 숫자뿐이고,
나머지(식·행렬·「풀이 참조」·「최댓값: 10, 최솟값: 1」)는 **글자로 넣으면 안 된다.**

그래서 다시쓰기는 **숫자 22 · 그림으로 되돌릴 것 159** 로 갈렸다.
그림으로 되돌리면 학생이 정답 그림을 보고 O/X 를 누른다(`app/grade/[code]/page.tsx` 의 자기채점).
