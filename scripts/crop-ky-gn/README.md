# 개념+유형(비상) 개념편 공통수학1 → 문항 이미지 (2026-09-21)

글자 PDF 2개: `개념+유형 공통수학1_개념편_.pdf`(q.pdf) · `개념+유형 공통수학1_정답과해설.pdf`(sol.pdf)

## 책 구조
- **필수예제 130개** — 문제 + 풀이(모범답안)가 한 쪽에 같이 있다. 예제 제목이 곧 유형 이름
- **문제(유제) 315개** — 예제 아래 `01-1`, `01-2` … 정답은 해설 PDF
- 개념 Check(빈칸)·개념 Plus(설명)는 문제가 아니라 제외

|---|---|

## 주의점 (이 책 특유)
- **예제 번호가 중단원마다 01부터 다시 시작**한다 → 파일 이름은 학원 소단원 + 그 단원 안 순번으로 새로 매겼다 (`0101`, 유제는 `0101S1`)
- 정답 글꼴: 답은 `YDVYMjO14`/`NPBIE`, 풀이는 `YDVYMjO12·13`/`NPIE` → 이걸로 답과 풀이를 가른다. **첫 번째 풀이 글자는 y 좌표로 찾아야 한다**(글자 순서가 위치 순서가 아님)
- **√가 글자가 아니라 그림**으로 들어간 답이 있다(0108S2 = 5√2, 0603S2 = 2√2). 글자만 보면 `52`, `22`로 읽혀 자동채점이 틀린다 → 숫자 정답 128개를 전부 눈으로 확인하고 이 둘만 자기채점으로 바꿨다
- 레벨: 예제·유제 모두 **2** (원장님 선택, 2026-09-21)
