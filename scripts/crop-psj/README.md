# 풍산자 필수유형 PDF → 문항 이미지 (공통수학1, 2026-09-19)

쎈과 달리 **글자가 살아 있는 PDF**라서 번호·정답을 글자로 바로 읽는다 (OCR 불필요).

- `crop.py` : 문제 PDF(`q.pdf`)에서 번호(Leferi 16pt 3자리)·유형 머리(KoreanGD18 2자리)·'풀이' 칸을 찾아
  다음 표시 직전까지 잘라 `out/q/NNN.png`, 상중하 배지는 `out/band/`
- `ans.py` : 정답과 풀이(`sol.pdf`)에서 번호 뒤의 `정답_ …` 줄만 잘라 `out/a/NNN_a.png` + 글자 정답
- `final.py` : 책 유형 → 학원 유형(`B2S`), 서술형·고득점은 문제를 보고 정한 `PER` 표. 레벨: 하2·중3·상4, 서술형3, 고득점4
- `build01.py` : 한 단원 확인용 HTML

다른 풍산자(라이트유형 등)나 공통수학2는 폰트 이름·단원 시작 번호(`BOOKCH_START`)·`B2S`·`PER`를 새로 맞춘다.
