# 수학의지혜 — 새로 오신 선생님께

저희 학원은 **프로그램 네 개**를 씁니다. 하는 일이 겹치지 않게 나눠 놓았습니다.
출근 전에 한 번씩 들어가 보시고, 눈에 익혀 두시면 첫날이 훨씬 수월합니다.

각 사이트 주소와 아이디·비밀번호는 따로 보내 드립니다.

---

## 1. 스터디체크 — 수업 기록

**선생님이 가장 많이 쓰시게 될 곳입니다.** 수업하고 나서 기록을 남기는 자리예요.
여기 적으신 내용이 학부모님께 카톡으로 나가고, 학생도 자기 화면에서 봅니다.

하루 흐름은 이렇습니다.

| | |
|---|---|
| ① 출근하면 | **대시보드** — 오늘 할 일과 전달사항 |
| ② 수업 후 | **학습관리** — 수업일지 저장 + 알림장 |
| ③ 과제 | **학습지관리** — 제출확인 → 점수입력 → 다음 단계 |
| ④ 마무리 | 대시보드에 「오늘 모든 업무 완료!」가 뜨면 끝 |

왼쪽 메뉴의 **「사용 매뉴얼」** 에 초등부·중등부·고등부가 나뉘어 있습니다.
담당하실 부를 눌러 한 번 읽어 주세요. 평가·학습지·레벨 기준이 거기 다 있습니다.

> 학부모님께 나가는 글이라 **오타와 문장**을 한 번 더 봐 주시면 좋습니다.
> 밤에 자동으로 다듬는 장치가 있지만, 선생님 글이 가장 정확합니다.

---

## 2. 수학OPS — 학원 운영

학원 **운영 관리** 프로그램입니다. 학생 등록, 출결, 결석 보강, 추가수업,
수업 횟수 같은 것이 여기서 관리됩니다.

**선생님께서도 쓰십니다 — 학생 교재를 요청하실 때 여기서 하세요.**

스터디체크와 **서로 연결**되어 있어서, 한쪽에서 바꾸면 다른 쪽에도 반영됩니다.
**내 학생이 보강이나 추가수업으로 언제 오는지**도 여기서 정해집니다.

---

## 3. 메이크에듀 — 근태 · 학생 문자

두 가지를 씁니다.

- **근태관리** — 선생님 본인 출퇴근 기록
- **학생 문자 전송** — 학생·학부모께 문자 보낼 때

---

## 4. 매쓰홀릭 — 문제은행

문제은행입니다. 주로 쓰는 기능은 **학습지, 진단평가, 오답유사, 오답문제** 등입니다.

---

## 미리 해 보시면 좋은 것

1. **스터디체크 로그인** → 대시보드가 뜨는지 확인
2. **사용 매뉴얼 → 담당하실 부** 한 번 읽기
3. 나머지 세 곳도 로그인만 한 번씩 (비밀번호 바꾸라고 하면 바꿔 주세요)

각각 기능 살펴보시면서 **궁금하신 건 언제든 문의해 주세요.**

> **교재나 과정에 대한 의견은 언제든 환영합니다.** 특히 고등부는 저희도
> 맞춰 가는 중이라, 필요한 교재나 있었으면 하는 과정이 보이시면 편하게 말씀해 주세요.
