# 출제 → 인쇄 → QR 채점 → 재출제

이 앱의 핵심 흐름. **어느 교재에서 나온 문항이든 이 흐름을 똑같이 탈 수 있어야 한다.**

## 전체 그림

```
[원장]  학습지출제 → 문제은행에서 조건 선택 → 출제
          ↓ exam_sheets + exam_sheet_problems 생성 (6자리 코드)
        인쇄 화면 (A4 2단, 우상단 QR)
          ↓ 출력해서 학생에게 배부
[학생]  풀고 → QR 스캔 → /grade/{code}
          ↓ 이름 선택 → 답 입력 → 제출
        점수 + 틀린 문항 + 약한 유형 즉시 표시
          ↓ gradings + grading_answers 저장
[원장]  채점결과 화면 → 학생별로
          · 틀린 문제 그대로 다시 출력
          · 쌍둥이 문제 출력
          · 같은 유형 다른 문제 출력
          ↓ 새 시험지 생성 → 다시 인쇄 → 다시 QR
```

학생마다 틀린 문제가 다르므로 **재출제는 학생 개별로** 이뤄진다.

## 테이블

```
exam_sheets(id, code UNIQUE, title, grade, semester, note,
            show_source, show_difficulty, kind, created_at)
exam_sheet_problems(sheet_id, no, problem_id)        PK(sheet_id, no)
gradings(id, sheet_id, student_id, student_name, score, total, submitted_at)
grading_answers(grading_id, no, problem_id, type_code,
                student_answer, is_correct)          PK(grading_id, no)
```

`code`는 6자리. 헷갈리는 글자를 뺀 `ABCDEFGHJKLMNPQRSTUVWXYZ23456789`에서 뽑는다 (O·0·I·1 제외).

## 코드 위치

| 하는 일 | 파일 |
|---|---|
| 조건 걸고 문항 뽑기 / 시험지 생성 | `app/api/problem-bank/route.ts` (POST) |
| 문제은행 화면 | `app/teacher/problem-bank/page.tsx` |
| 재출제 시험지 생성 + 인쇄 데이터 | `app/api/reprint/route.ts` |
| 인쇄 화면 | `app/teacher/gradings/print/page.tsx` |
| QR 채점 화면 (학생) | `app/grade/[code]/page.tsx` |
| QR 채점 서버 | `app/api/grade/[code]/route.ts` |
| 채점결과 (원장) | `app/teacher/gradings/page.tsx` |

## 채점 판정

```ts
choice : 학생이 고른 번호들을 정렬해 정답과 문자열 비교 (복수정답 지원)
number : 공백·쉼표 제거 후 비교
image  : 정답을 글자로 못 뽑은 문항 → 학생이 스스로 O/X 체크
```

정답은 DB에 `①②③④⑤` 기호로 저장돼 있고, 서버에서 `'③, ⑤' → ['3','5']`로 변환해 내려준다.

## 문항 뽑기 방식 (`mode`)

```
even   유형을 돌아가며 한 문제씩  ← 기본값. 고른 유형이 고루 들어간다
random 무작위
focus  쉬운 것부터 (대표 → 하 → 중 → 상)
hard   어려운 것부터
```

- `perTypeMax` : 유형당 최대 문항 수 (0 = 제한없음)
- `noRepeat` : 지금까지 만든 시험지에 들어간 문항을 뺀다. **단, 남는 문항이 너무 적으면 무시한다**
  (조건이 빡세서 아예 출제가 안 되는 걸 막기 위함)
- 최종 정렬은 유형코드 → 교재(베이직쎈→쎈B→쎈) → 문항번호

## 재출제 3종 (`app/api/reprint/route.ts`)

| mode | 내용 |
|---|---|
| `wrong` | 틀린 문제 그대로 |
| `twin` | `twin_id`로 연결된 쌍둥이 문제 |
| `similar` | 같은 `type_code`의 다른 문제. **이미 낸 문항과 그 쌍둥이는 제외** |

## 인쇄 시험지

A4 2단. 상단에 로고·제목·QR, 정보 입력칸(학년반/이름/점수), 하단에 문구와 캐릭터.
`show_source`(쎈 몇 번·유형 표시)와 `show_difficulty`(난이도 배지)로 출처 노출을 끌 수 있다.
학생에게 나가는 시험지는 보통 둘 다 끄는 게 낫다.

**문항 이미지 crop은 교재별로 다르다 — `docs/문제은행.md` 참고.**
