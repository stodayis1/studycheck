# 운영 매뉴얼 (원장님용)

개발 지식 없이 읽는 문서입니다. **다른 AI나 개발자에게 이 시스템을 맡길 때 이 문서부터 보여주세요.**

## 이 시스템이 뭘로 굴러가나

세 곳에 나뉘어 있습니다.

| 어디 | 무엇이 있나 | 없어지면 |
|---|---|---|
| **GitHub** | 코드 전부 | 과거 버전까지 다 남아 있어 복구 쉬움 |
| **Vercel** | 웹사이트를 띄우는 곳 | 코드만 있으면 다시 만들 수 있음 |
| **Supabase** | **학생·진도·문제·채점 데이터 전부** | **여기가 진짜 위험. 백업 확인 필수** |

**AI가 없어도 학원 앱은 멈추지 않습니다.** 앱은 Vercel과 Supabase에서 스스로 돌아갑니다.
AI가 필요한 건 "고치거나 새로 만들 때"뿐입니다.

## 새 AI나 개발자에게 맡길 때

그냥 이렇게 말씀하시면 됩니다.

> "studycheck 저장소의 `AGENTS.md`와 `docs/` 폴더를 먼저 읽어줘."

거기에 구조·규칙·함정이 다 적혀 있습니다. GPT, Claude, 다른 개발자 누구든 통합니다.
특정 AI 전용 백업을 따로 만들 필요는 없습니다.

## 절대 하면 안 되는 것

1. **Supabase에서 테이블을 지우거나 컬럼을 없애는 변경**에 그냥 "예"를 누르지 마세요.
   데이터가 사라지면 백업 시점으로만 돌아갑니다.
2. **`SUPABASE_SERVICE_ROLE_KEY` / `sb_secret_...` 키를 캡처하거나 공유하지 마세요.**
   이 키 하나면 모든 잠금장치가 무력화됩니다. AI에게도 보내지 마세요.
   (`sb_publishable_...`는 공개용이라 괜찮습니다.)
3. **Vercel 환경변수 "이름"을 바꾸지 마세요.** 값만 바꿉니다.
4. 앱이 잘 돌아가는 걸 확인하기 전에 **Supabase에서 옛날 키를 끄지 마세요.**

## 정기적으로 확인하면 좋은 것

**분기에 한 번 정도**

- Supabase → Database → **Backups** 에 백업이 쌓이고 있는지
- **문제 이미지 원본**(`C:\Users\USER\문제은행`)이 외장하드나 클라우드에도 한 벌 있는지
  → DB 백업에 이미지는 안 들어갈 가능성이 큽니다. 날아가면 문제은행이 텅 빕니다
- 퇴사한 선생님 계정이 남아 있지 않은지 (선생님 계정은 학생 정보를 전부 봅니다)

**큰 작업이 끝날 때마다**

- AI에게 "`docs/` 문서도 갱신해줘"라고 한마디 해주세요. 그래야 이 문서가 낡지 않습니다

## 자주 겪는 상황

| 상황 | 대처 |
|---|---|
| 배포하고 나서 화면이 이상하다 | Vercel → Deployments → **Instant Rollback** (직전 버전으로 즉시 복구) |
| 학생이 "로그인이 안 된다" | 이름 + 보호자 전화 뒷 4자리가 맞는지. 5번 틀리면 15분 잠깁니다 |
| 동명이인 학생 | 이름 뒤에 전화 뒷4자리를 붙여 입력 (예: 홍길동1234) |
| 화면이 비어 보인다 | `Ctrl+Shift+R` (강력 새로고침) 먼저 |
