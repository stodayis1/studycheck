### 쎈 공통수학1 (고등) — 2026-09-18
- `grade='공통수학1'`, `semester=1`, `local_no`는 책 번호 그대로 4자리(`'0001'`~`'1316'`), `step` = A/B/C
- 레벨: A=1, B=3 (B의 '상'은 4), C=4. 유형은 A·B·C 전부 붙어 있다
  - A: 책에 유형 표시가 없어 문제 내용을 보고 붙임
  - B: 대표문제(빨간 상자) 순서 = 유형 번호
  - C: 책에 적힌 "○쪽 유형 □□" 중 **첫 번째** (01단원만 유형 12 도형 활용이 있으면 12)
- 정답: ①~⑤ 선택형 425개만 `answer_kind='choice'`, 나머지는 `image`(학생 자기채점).
  숫자 답은 OCR이 −3을 3으로 읽는 등 믿을 수 없어 일부러 글자로 넣지 않았다
- 이미지 경로: `hc1-1/ssen/{소단원}/{0001}.png` (정답 `_a.png`). 쎈과 같은 37px 번호 머리글 형식
- 원본/잘린 이미지: `C:\Users\USER\문제은행\고등\` · 데이터: `scripts/problems_ssen_cm1.json`
- 업로드: `node scripts/upload-problems.mjs "<폴더>" scripts/problems_ssen_cm1.json`
  (세 번째 인자로 데이터 파일 지정, `lv`/`k`/`a` 키가 있으면 level·정답도 같이 들어간다)

- 유형 분류가 된 문항: 11,419개. 안 된 1,108개는 **쎈 C단계(심화)** — 유형표에 대응이 없다.
- 표준 유형표 `standard_types`: 915개 유형 (대단원 > 소단원 > 유형)
- 쌍둥이 쌍: 4,025쌍 (쎈 ↔ 쎈B)
- 이미지: Storage 비공개 버킷 `problem-images`에 23,257장

## 테이블

### standard_types (유형표 — 모든 것의 기준)
```
code              중1-1-08-01  ← 학년-학기-소단원-유형
grade semester    중1 / 1
chapter_no/title  대단원
sub_chapter_no/title  소단원
type_no/title     유형 번호·이름
is_focus          중요 유형 표시
```

### problems (문항)
```
id book grade semester sub_chapter_no local_no
type_code    → standard_types.code
step         쎈: B/C · 베이직쎈: A(기본핵심) / T(학교시험기출)
difficulty   대표 / 하 / 중 / 상  (베이직쎈은 null — step으로 대신함)
is_essay is_important
answer_kind  choice(6,023) / number(1,451) / image(5,053)
answer_text  '③' 또는 '③, ⑤' 또는 숫자
image_path   Storage 경로
twin_id      쌍둥이 문항 id (양방향)
origin_no    쎈B 전용 — 대응하는 쎈의 local_no
```

`answer_kind='image'`는 답을 글자로 못 뽑은 것. QR 채점에서 **학생이 스스로 O/X 체크**하게 되어 있다.

### 레벨 1~6 — 학원 공통 난이도 (제일 중요한 규칙)

교재마다 난이도 표기가 제각각이라, **학원 공통 자**를 하나 두고 `problems.level`에 1~6을 넣는다.
이게 학습지 출제·학생 수준 판단의 기준이다. **새 교재를 올릴 때 레벨을 안 정하고 올리면 안 된다.**

| 레벨 | 기준 | 지금 해당하는 것 |
|---|---|---|
| 1 | 쎈 A스텝 수준 | 베이직쎈 A단계 (기본·핵심유형) 2,549 |
| 2 | 개념원리·개념유형 등의 대표문제·확인문제 | 베이직쎈 T단계 (학교시험 기출) 819 |
| 3 | 쎈 B스텝 | 쎈 B단계 + 쎈B 의 대표/하/중 6,762 |
| 4 | 쎈 B스텝의 '상', 쎈 C스텝 | 쎈·쎈B 의 상 + 쎈 C단계 2,397 |
| 5 | 올림포스 고난도 | 아직 없음 |
| 6 | 고쟁이 최심화 | 아직 없음 |

- **쎈 B단계의 '상'도 4다.** 쎈과 쎈B는 1:1 쌍둥이(4,025쌍)라, 한쪽만 올리면 쌍둥이 출제 시
  레벨이 어긋난다.
- **쎈 C단계는 일단 전부 4로 묶었다.** 책에 난이도 표시가 없어 자동으로 못 가른다.
  레벨5로 뺄 문항은 원장님이 나중에 따로 지정한다.
- **교과서는 레벨을 매기지 않는다** (`level` = null). 학습지 출제 화면의
  '교재 연계 → 교과서' 탭에서 따로 뽑는다. 레벨 필터를 걸지 않는다.

기존 `step`, `difficulty` 값은 그대로 두었다. 규칙이 바뀌면 다시 계산하면 된다.

## 이미지 경로와 crop

경로: `{학년}-{학기}/{교재}/{소단원2자리}/{문항번호}.jpg`
예) `m3-1/ssen/07/778.jpg`

**crop 규칙 — 틀리면 문제가 깨진다:**
- 쎈 / 쎈B → 이미지 위 **37px을 잘라야 한다** (문항 번호 머리글이 따로 있음)
- **베이직쎈 → 자르면 안 된다 (0px).** 번호와 지문이 같은 줄에 있어서 자르면 문제가 사라진다

코드에서는 `crop: p.book === '쎈' || p.book === '쎈B'` 플래그로 넘기고, 인쇄 화면에서
`marginTop: -(37 / naturalWidth * 100)%` 로 처리한다.

## 새 교재 PDF를 넣을 때

원장님이 PDF를 주시면 다음 순서로 한다. **먼저 목차를 뽑아 보여드리고 확인받은 뒤에** 넣는다.
(2026-09 이너프원 작업에서 목차 순서를 임의로 바꿔 넣어 문제가 됐다. 같은 실수 반복 금지.)

1. PDF에서 문항별 이미지로 자르기
2. 표준 유형표(`standard_types`)에 맞춰 유형 분류
3. `scripts/problems_data.json` 형태로 만들고 `scripts/upload-problems.mjs` 실행
   (이미지는 Storage로, 메타데이터는 `problems`로 올라간다)
4. QR 채점 플로우(`app/grade/[code]`, `app/teacher/gradings/print`)가 새 문항에서도 되는지 확인

`anthropic-skills:problem-bank-textbook-upload` 스킬에 이 파이프라인이 정리돼 있다.

## 이너프원 (`inner_enough` 테이블) — 별개 시스템

학교별 내신 대비 교재 진도표. 문제은행과는 다른 테이블이다.

```
school_name  '신원중' 또는 '공통_평면좌표~집합'(고등)
grade        '1','2','3'  (중1/중2/중3 또는 고1)
level        상/중/하/표준  또는 S/B
unit_no unit_name            대단원
sub_unit_no sub_unit_name    소단원
problem_count
```

**주의: `unit_no`의 의미가 교재마다 다르다.**
- 중등 교재 / 2026-05 업로드 고등 2종 → `unit_no` = **실제 수학 단원** (방정식과 부등식, 경우의 수, 행렬…)
- 2026-09 업로드 `공통_평면좌표~집합` → `unit_no` = **교재 섹션** (빈출유형/교과서기출/서술형/…)
  이 책은 섹션이 대단원 역할을 하므로 이게 맞다.

`공통_평면좌표~집합`의 확정된 순서 (PDF 목차 기준):
```
1 빈출 유형              57문항
2 교과서 기출            56
3 서술형                 35
4 중간고사 대비 실전 모의고사  1·2·3회       60
5 최다빈출 공략          단원별 01/02 10개  200
6 실전 모의고사          1~6회차            120
```

새 이너프원 PDF를 넣을 때는 **반드시 PDF 목차 순서를 먼저 확인하고 원장님께 보여드린 뒤** 넣을 것.
