# 진로·활동 기록

원장님 2026-11-07 — 학생의 진로와 학교 활동(탐구보고서·세특 등)을 학원이 한곳에 기록·관리한다.
진로 정보는 **입학 동의와 별도로** 개인정보 수집·이용 동의를 받은 뒤에만 받는다.

## 화면
| 누가 | 어디 | 하는 일 |
|---|---|---|
| 학생 | `/student/career` (대시보드 「진로 설문」 띠) | 동의 → 설문 → 고치기 · 동의 철회 |
| 학부모 | `/parent/career` (대시보드 띠) | 위와 같음. 학생과 **따로** 낸다 |
| 선생님 | `/teacher/career` (사이드바 학생 › 진로·활동 기록) | ① 설문 안내·미리보기·테스트 학생으로 해 보기 ② 응답 현황·안내 문자 ③ 학생별 기록 |

- 띠와 설문은 **중3(예비고1)·고1(예비고2)** 에게만 열린다 (`formForGrade`). 다른 학년은 띠가 안 뜬다.
- **테스트 학생**(원장님 = 윤수지, 강사 = 테스트, `lib/testStudents.ts`)은 학년과 상관없이 두 설문이 다 열린다.
  선생님 화면 「테스트 학생으로 해 보기」는 `/api/career/test`(직원만, 대상은 본인 테스트 학생으로 고정)로 저장한다.
- 설문지 모양은 학부모 설문(`app/survey/[key]`)과 같은 꼴 — `components/career/CareerSurveyForm.tsx` 하나를 학생·학부모·미리보기·테스트가 같이 쓴다.
- 강사는 본인 담당 학생만 보이고(`canViewStudent`), 주임모드는 보기만(`canEditStudent`).

## 데이터 (SQL: `docs/sql/진로활동기록.sql` · 되돌리기 `_되돌리기.sql`)
| 표 | 내용 | 쓰기 |
|---|---|---|
| `career_consents` | 동의 기록. 판(`consent_version`)·필수/선택·철회 시각 | `/api/career` 만 (service_role) |
| `career_surveys` | 설문 답 (`survey_key` = `2026-겨울-예비고1` 등, 학생/학부모 따로) | `/api/career` 만 |
| `student_activities` | 탐구보고서·세특·수행평가·동아리… 활동 기록 | 직원 (RLS insert/update). delete 정책 없음 — 지우기는 `deleted_at` |

세 표 모두 **직원만 읽는다.** 학생·학부모 세션으로 읽으면 0행이다(2026-11-07 확인).

## 바꿀 때
- 문항·보기: `lib/careerSurvey.ts` 의 `QUESTIONS` 한 곳. 서버가 여기 없는 보기는 버린다.
- 동의서 문구: `CONSENT_TEXT` 를 고치면 **`CONSENT_VERSION` 을 올린다** → 모두 다시 동의를 받는다.
- 다음 차수 설문: `SURVEY_ROUND` 만 바꾼다(지난 답은 남는다). 학년이 올라가면 `formForGrade` 도 확인.
- 보유 기간: 동의일부터 3년 (원장님 2026-11-07). 기간이 지난 행을 지우는 일은 아직 자동이 아니다.
