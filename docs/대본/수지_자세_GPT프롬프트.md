# 수지쌤 자세 더 그리기 — GPT 프롬프트 (2026-10-22)

목표: 모든 자세에서 **입 다문 그림 + 입 벌린 그림** 두 장이 있어야, 말할 때 입이 움직인다.
저장 자리: `scripts/lesson-video/suji/poses/<이름>_closed.png`, `<이름>_open.png` — 그려서 다운로드 폴더에 이 이름으로 저장해 주시면 제가 옮기고 검사한다.

## 공통으로 꼭 지킬 것 (모든 프롬프트 끝에 붙어 있음)
- 첨부한 그림의 수지와 **완전히 같은 캐릭터**: 검은 단발, 둥근 검은 뿔테 안경, 파란 교복 재킷, 빨간 넥타이, 회색 주름치마, 매끈한 3D 클레이 느낌
- **정사각형 1254×1254, 배경 투명 PNG**
- 캐릭터 크기·위치를 첨부 그림과 같게(머리 위 여백, 치마 아래 끝 위치가 같게), 글자·로고·그림자 바닥 없음
