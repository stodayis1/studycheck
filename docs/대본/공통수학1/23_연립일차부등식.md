## 1. 연립일차부등식

**슬라이드에 적을 것**

연립일차부등식
- 연립일차부등식의 풀이
- A<B<C 꼴
- 특수한 해

**수지쌤이 말할 것**

오늘은 연립일차부등식을 배웁니다. 일차부등식 두 개를 동시에 만족하는 엑스의 범위를 구하는 방법입니다.

## 2. 왜 필요한가

**슬라이드에 적을 것**

조건이 2개 이상 → 연립
시험: 직접 풀기 / 해가 주어진 문제 / 정수인 해의 개수

**수지쌤이 말할 것**

조건이 두 개 이상일 때 연립부등식을 씁니다. 어떤 수보다 크면서 동시에 다른 수 이하여야 하는 경우가 그렇습니다. 시험에서는 연립부등식을 직접 풀게 하거나, 해가 주어졌을 때 문자의 값을 구하게 하거나, 정수인 해가 몇 개인지 묻습니다. 모두 오늘 배우는 풀이가 바탕입니다.

## 3. 연립일차부등식의 풀이

**슬라이드에 적을 것**

각각 풀기 → 수직선에 그리기 → 공통부분
$\begin{cases}x+2>4\\3x-1\le 8\end{cases}$
$x>2,\ x\le 3$
답: $2<x\le 3$

**수지쌤이 말할 것**

먼저 연립일차부등식의 풀이입니다. 각 부등식을 따로 풀고, 두 해의 공통부분을 구합니다. 연립은 둘 다 동시에 만족해야 한다는 뜻이라서 겹치는 부분만 답이 됩니다. 예를 들어 엑스 더하기 이가 사보다 크다에서는 엑스가 이보다 크고, 삼 엑스 빼기 일이 팔 이하다에서는 엑스가 삼 이하입니다. 수직선에 그리면 겹치는 부분은 이 초과 삼 이하입니다.

## 4. A<B<C 꼴의 부등식

**슬라이드에 적을 것**

$A<B<C \Rightarrow \begin{cases}A<B\\B<C\end{cases}$
또는 세 변에 같은 연산
$1<2x-1\le 5$
$2<2x\le 6$
$1<x\le 3$

**수지쌤이 말할 것**

다음은 A 작다 B 작다 C 꼴입니다. 이 식은 A 작다 B와 B 작다 C를 동시에 만족한다는 뜻이라서, 둘로 나눠 연립으로 풀 수 있습니다. 더 간단하게는 세 변에 똑같은 연산을 해도 됩니다. 일 작다 이 엑스 빼기 일 작거나 같다 오에서 모든 변에 일을 더하면 이 작다 이 엑스 작거나 같다 육이고, 이로 나누면 엑스는 일 초과 삼 이하입니다. 세 변에 똑같이 해야 한다는 점이 중요합니다.

## 5. 특수한 해

**슬라이드에 적을 것**

$x\ge 3,\ x\le 3 \Rightarrow x=3$
$x>3,\ x<3 \Rightarrow$ 해 없음
$x>3,\ x\le 3 \Rightarrow$ 해 없음

**수지쌤이 말할 것**

공통부분이 특별한 경우도 있습니다. 엑스가 삼 이상이고 삼 이하이면 겹치는 곳이 한 점이라서 엑스는 삼입니다. 엑스가 삼보다 크고 삼보다 작으면 겹치는 곳이 없어서 해가 없습니다. 엑스가 삼 초과이고 삼 이하여도 해가 없습니다. 경계의 삼이 두 쪽에 모두 포함되는지가 기준입니다.

## 6. 정리

**슬라이드에 적을 것**

외울 것: 각각 풀고 공통부분
실수: 등호 포함 여부, 음수로 나눌 때 부등호 방향

**수지쌤이 말할 것**

외울 것은 각각 풀고 수직선에서 공통부분을 찾는다는 한 줄입니다. 흔한 실수는 경계값의 등호를 빠뜨리거나, 음수를 곱하거나 나눌 때 부등호 방향을 바꾸지 않는 것입니다. 공통부분이 없으면 해 없음이라고 써야 한다는 점도 기억하세요.
