## 1. 이차방정식의 근의 판별

**슬라이드에 적을 것**

판별식 $D=b^2-4ac$
근을 풀지 않고 근의 종류를 알아낸다

**수지쌤이 말할 것**

이번 시간에는 이차방정식의 근의 판별을 배웁니다. 방정식을 직접 풀지 않고도 근이 어떤 종류인지 알아내는 방법입니다.

## 2. 왜 필요한가

**슬라이드에 적을 것**

· 계수에 문자가 있을 때 근의 종류 판단
· 문자의 값의 범위 구하기
· 삼각형의 모양, 완전제곱식 조건으로 이어짐

**수지쌤이 말할 것**

시험에는 계수에 문자가 들어 있는 이차방정식이 나옵니다. 이 방정식이 서로 다른 두 실근, 중근, 허근 중 무엇을 갖는지 묻거나, 그렇게 되도록 하는 문자의 값의 범위를 구하게 합니다. 판별식과 삼각형의 모양, 이차식이 완전제곱식이 되는 조건 문제도 같은 원리로 풉니다.

## 3. 판별식과 세 가지 경우

**슬라이드에 적을 것**

$ax^2+bx+c=0$ (계수는 실수)
$D=b^2-4ac$
$D>0$ : 서로 다른 두 실근
$D=0$ : 중근
$D<0$ : 서로 다른 두 허근

**수지쌤이 말할 것**

계수가 실수인 이차방정식 에이 엑스 제곱 더하기 비 엑스 더하기 씨 는 영에서, 근의 공식의 루트 안에 있는 비 제곱 빼기 사 에이 씨를 판별식이라 하고 디로 씁니다. 근은 루트 안의 부호로 정해지기 때문입니다. 디가 양수면 플러스 마이너스로 서로 다른 두 실근이 나옵니다. 디가 영이면 두 값이 같아져 중근입니다. 디가 음수면 루트 안이 음수라서 서로 다른 두 허근입니다.

## 4. 문자가 있을 때의 풀이

**슬라이드에 적을 것**

$x^2-4x+k=0$
$\frac{D}{4}=(-2)^2-k=4-k$
$k<4$ : 서로 다른 두 실근
$k=4$ : 중근
$k>4$ : 서로 다른 두 허근

**수지쌤이 말할 것**

엑스 제곱 빼기 사 엑스 더하기 케이 는 영을 봅시다. 일차항의 계수가 짝수이면 디 나누기 사, 즉 비 프라임 제곱 빼기 에이 씨를 쓰는 편이 계산이 간단합니다. 여기서는 사 빼기 케이가 됩니다. 케이가 사보다 작으면 서로 다른 두 실근, 사와 같으면 중근, 사보다 크면 서로 다른 두 허근입니다.

## 5. 중근과 완전제곱식

**슬라이드에 적을 것**

$x^2+6x+k$ 가 완전제곱식
$\Rightarrow D=0$
$36-4k=0,\ k=9$
$x^2+6x+9=(x+3)^2$

**수지쌤이 말할 것**

중근을 가지면 이차식이 완전제곱식이 됩니다. 근이 하나뿐이라 한 일차식의 제곱으로 묶이기 때문입니다. 그래서 엑스 제곱 더하기 육 엑스 더하기 케이가 완전제곱식이려면 디가 영입니다. 삼십육 빼기 사 케이가 영이므로 케이는 구입니다. 실제로 엑스 더하기 삼의 제곱이 됩니다.

## 6. 정리

**슬라이드에 적을 것**

외울 것: $D=b^2-4ac$ / $D>0$, $D=0$, $D<0$
실수: 실근을 가진다 $\Rightarrow D\ge 0$ (등호 포함)
실수: 이차항 계수에 문자가 있으면 $a\ne 0$ 확인

**수지쌤이 말할 것**

외울 것은 판별식 비 제곱 빼기 사 에이 씨와, 디의 부호에 따른 세 가지 경우입니다. 흔한 실수가 두 가지 있습니다. 실근을 가진다는 조건에는 중근이 포함되므로 디가 영보다 크거나 같다고 써야 합니다. 또 이차항의 계수에 문자가 있으면 그 문자가 영이 아닌지 꼭 확인하세요.
