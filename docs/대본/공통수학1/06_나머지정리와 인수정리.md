## 3. 나머지정리

**슬라이드에 적을 것**

$f(x)=(x-a)Q(x)+R$
$x=a$ 대입 → $R=f(a)$

예) $f(x)=x^3-2x^2+3x+1$을 $x-2$로 나눈 나머지
$f(2)=8-8+6+1=7$

**수지쌤이 말할 것**

다항식 f(x)를 x 빼기 a로 나눈 몫을 Q(x), 나머지를 R이라 하면, f(x)는 x 빼기 a 곱하기 Q(x) 더하기 R입니다. 일차식으로 나누기 때문에 나머지 R은 상수입니다. 이 식은 항등식이니까 x에 a를 넣어도 성립합니다. 그러면 x 빼기 a가 0이 되어 앞부분이 사라지고, f(a)는 R과 같아집니다. 그래서 나머지는 f(a)입니다. 예를 들어 f(x)가 x 세제곱 빼기 2x 제곱 더하기 3x 더하기 1일 때, x 빼기 2로 나눈 나머지는 f(2), 즉 8 빼기 8 더하기 6 더하기 1, 7입니다.

## 4. 인수정리

**슬라이드에 적을 것**

$f(a)=0 \iff (x-a)$는 $f(x)$의 인수

예) $x^2+kx-6$이 $x-2$로 나누어떨어질 때
$f(2)=4+2k-6=0$ → $k=1$

**수지쌤이 말할 것**

나머지가 0이면 나누어떨어진다는 뜻이고, 이때 x 빼기 a는 f(x)의 인수입니다. 나머지정리에서 R이 f(a)이니까, f(a)가 0이면 인수라는 것이 그대로 나옵니다. 이것이 인수정리입니다. 예를 들어 x 제곱 더하기 k x 빼기 6이 x 빼기 2로 나누어떨어지려면 f(2)가 0이어야 합니다. 4 더하기 2k 빼기 6이 0이니까 k는 1입니다.

## 5. ax+b로 나눌 때

**슬라이드에 적을 것**

$f(x)$를 $ax+b$로 나눈 나머지
$= f\left(-\dfrac{b}{a}\right)$

예) $2x-1$로 나누면 $f\left(\dfrac12\right)$

**수지쌤이 말할 것**

나누는 식이 x 빼기 a 꼴이 아니라 a x 더하기 b일 때도 원리는 같습니다. 나누는 식이 0이 되는 x의 값을 넣으면 됩니다. 그 값이 마이너스 a분의 b입니다. 예를 들어 2x 빼기 1로 나눌 때는 x에 2분의 1을 넣어 f(2분의 1)을 계산합니다.

## 6. 정리

**슬라이드에 적을 것**

외울 것: 나머지 $=f(a)$, $f(a)=0$이면 $x-a$는 인수
실수: $x+3$으로 나누면 $f(-3)$ ($f(3)$ 아님)

**수지쌤이 말할 것**

외울 것은 한 줄입니다. x 빼기 a로 나눈 나머지는 f(a)이고, f(a)가 0이면 x 빼기 a는 인수입니다. 가장 흔한 실수는 부호입니다. x 더하기 3으로 나누면 f(3)이 아니라 f(마이너스 3)을 계산해야 합니다. a x 더하기 b일 때도 마이너스 a분의 b를 넣는다는 점을 꼭 기억하세요.
