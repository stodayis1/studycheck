## 1. 부정방정식

**슬라이드에 적을 것**

부정방정식
- 식의 개수 < 미지수의 개수
- 조건(정수·실수)으로 해를 구한다

**수지쌤이 말할 것**

이번 시간에는 부정방정식을 배웁니다. 식은 하나인데 구해야 할 미지수는 둘인 방정식을, 문제에 붙은 조건을 이용해서 푸는 방법입니다.

## 2. 왜 필요한가

**슬라이드에 적을 것**

식 1개, 미지수 2개 → 해가 무수히 많다
조건이 붙으면 해가 좁혀진다
· $x, y$ 가 정수일 때
· $x, y$ 가 실수일 때

**수지쌤이 말할 것**

미지수는 둘인데 식이 하나면, 보통 해가 무수히 많아서 하나로 정해지지 않습니다. 그런데 엑스, 와이가 정수라거나 실수라는 조건이 붙으면 해가 몇 개로 좁혀집니다. 시험에서는 바로 이 조건을 붙여서 해를 구하라고 묻습니다. 그래서 문제를 보면 정수 조건인지 실수 조건인지부터 확인하는 것이 출발점입니다.

## 3. 정수 조건: 곱의 꼴로

**슬라이드에 적을 것**

$xy-2x-y=3$
$(x-1)(y-2)=5$
$(x-1,\,y-2)=(1,5),(5,1),(-1,-5),(-5,-1)$
$(x,y)=(2,7),(6,3),(0,-3),(-4,1)$

**수지쌤이 말할 것**

정수 조건이면 식을 일차식 곱하기 일차식은 정수, 이 꼴로 바꿉니다. 예를 들어 엑스 와이 빼기 이 엑스 빼기 와이는 삼에서, 양변에 이를 더하면 엑스 빼기 일 곱하기 와이 빼기 이는 오가 됩니다. 정수끼리 곱해서 오가 되는 쌍은 일과 오, 오와 일, 마이너스 일과 마이너스 오, 마이너스 오와 마이너스 일, 이렇게 네 가지뿐입니다. 약수의 쌍이 유한하기 때문에 해가 정해지는 겁니다. 엑스 빼기 일이 일이고 와이 빼기 이가 오이면 엑스는 이, 와이는 칠이고, 나머지 쌍도 같은 방법으로 구합니다.

## 4. 실수 조건: 제곱의 합이 0

**슬라이드에 적을 것**

$x^2+y^2-4x+6y+13=0$
$(x-2)^2+(y+3)^2=0$
$A, B$ 실수일 때 $A^2+B^2=0 \iff A=0,\ B=0$
$x=2,\ y=-3$

**수지쌤이 말할 것**

실수 조건이면 완전제곱식으로 정리해서 제곱의 합 꼴로 만듭니다. 엑스 제곱 더하기 와이 제곱 빼기 사 엑스 더하기 육 와이 더하기 십삼은 영을 정리하면, 엑스 빼기 이의 제곱 더하기 와이 더하기 삼의 제곱은 영이 됩니다. 실수의 제곱은 항상 영 이상이기 때문에, 둘을 더해서 영이 되려면 둘 다 영이어야 합니다. 그래서 엑스는 이, 와이는 마이너스 삼입니다.

## 5. 정리

**슬라이드에 적을 것**

외울 것
· 정수 조건: (일차식)(일차식)=정수 → 약수 쌍 나열
· 실수 조건: 제곱의 합 $=0$ → 각각 $0$
실수 주의
· 음수 약수 쌍 빠뜨리기
· $x-1$ 의 값을 $x$ 로 되돌리지 않기

**수지쌤이 말할 것**

외울 것은 두 가지입니다. 정수 조건이면 곱의 꼴로 바꿔서 약수의 쌍을 나열하고, 실수 조건이면 제곱의 합이 영인 꼴로 바꿔서 각각을 영으로 놓습니다. 자주 틀리는 부분은 음수인 약수의 쌍을 빠뜨리는 것, 그리고 엑스 빼기 일 같은 값을 구해 놓고 엑스로 되돌리는 것을 잊는 것입니다. 답을 구한 뒤에 원래 식에 넣어서 확인하는 습관을 들이세요.
