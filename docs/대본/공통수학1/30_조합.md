# 30. 조합

공통수학1 · 3. 경우의 수 · 경우의수
제목: 조합
슬라이드 6장 · 말 827자 (대략 150초)

---

## 1. 조합

**슬라이드에 적을 것**

조합: 순서 없이 뽑는 경우의 수
$_nC_r$

**수지쌤이 말할 것**

이번 시간에는 조합을 배웁니다. 서로 다른 것 중에서 순서를 생각하지 않고 몇 개를 뽑는 경우의 수를 구하는 방법입니다.

## 2. 왜 필요한가

**슬라이드에 적을 것**

대표 뽑기, 팀 짜기, 카드 고르기 → 순서 무관 → 조합
시험: 조합의 값 계산 / 뽑는 경우의 수 / 순열·조합 구별

**수지쌤이 말할 것**

대표를 뽑거나 팀을 짜거나 카드를 고르는 문제처럼, 순서가 상관없는 선택은 모두 조합입니다. 시험에서는 조합의 값을 계산하거나 조건에 맞게 뽑는 경우의 수를 묻습니다. 순열을 쓸지 조합을 쓸지 고르는 것이 핵심입니다.

## 3. 조합의 뜻

**슬라이드에 적을 것**

서로 다른 $n$개에서 순서 없이 $r$개를 뽑는 경우의 수 → $_nC_r$
예: A, B, C 중 2명 → AB = BA

**수지쌤이 말할 것**

서로 다른 엔 개에서 순서를 생각하지 않고 알 개를 뽑는 경우의 수를 조합이라 하고, 엔 씨 알이라고 읽습니다. 예를 들어 A, B, C 중에서 두 명을 뽑을 때 AB와 BA는 같은 경우로 봅니다. 그래서 순서까지 구분하는 순열보다 경우의 수가 적습니다.

## 4. 조합의 공식

**슬라이드에 적을 것**

$_nC_r=\dfrac{_nP_r}{r!}=\dfrac{n!}{r!\,(n-r)!}$
예: $_5C_2=\dfrac{5\times4}{2\times1}=10$

**수지쌤이 말할 것**

엔 씨 알은 엔 피 알을 알 팩토리얼로 나눈 값이고, 엔 팩토리얼 나누기 알 팩토리얼 곱하기 엔 빼기 알 팩토리얼과 같습니다. 이유는 이렇습니다. 순열에서는 뽑은 알 개를 줄 세우는 알 팩토리얼 가지가 모두 다른 경우로 세어지는데, 조합에서는 그것들이 한 가지이기 때문입니다. 예를 들어 오 씨 이는 오 곱하기 사를 이 곱하기 일로 나눈 십입니다.

## 5. 조합의 성질

**슬라이드에 적을 것**

$_nC_r={}_nC_{n-r}$
$_nC_0={}_nC_n=1$
예: $_{10}C_8={}_{10}C_2=45$

**수지쌤이 말할 것**

엔 씨 알은 엔 씨 엔 빼기 알과 같습니다. 알 개를 뽑는 것은 뽑지 않을 엔 빼기 알 개를 정하는 것과 같기 때문입니다. 알이 클 때는 이 성질로 줄여서 계산하면 편합니다. 예를 들어 십 씨 팔은 십 씨 이와 같아서 사십오입니다. 또 엔 씨 영과 엔 씨 엔은 모두 일입니다.

## 6. 정리

**슬라이드에 적을 것**

외우기: $_nC_r=\dfrac{n!}{r!\,(n-r)!}$
실수: 순서 무관한데 순열로 계산 / $r!$로 나누기 빼먹기

**수지쌤이 말할 것**

외울 것은 엔 씨 알이 엔 팩토리얼 나누기 알 팩토리얼 곱하기 엔 빼기 알 팩토리얼이라는 것입니다. 흔한 실수는 순서가 상관없는데 순열로 계산하거나, 알 팩토리얼로 나누는 것을 빠뜨리는 것입니다. 문제를 풀기 전에 순서가 바뀌면 다른 경우인지부터 확인하세요.
