# 4. 곱셈공식의 변형

제목: 곱셈 공식의 변형: 제곱의 합과 세제곱의 합

## 1. 곱셈 공식의 변형

**슬라이드에 적을 것**

합과 곱으로 $x^2+y^2$, $x^3+y^3$ 구하기
· 두 문자
· $x+\frac{1}{x}$ 꼴
· 세 문자

**수지쌤이 말할 것**

이번 시간에는 곱셈 공식의 변형을 배웁니다. 문자의 합과 곱만 알면 제곱의 합과 세제곱의 합을 구할 수 있습니다. 두 문자, 엑스 더하기 엑스분의 일 꼴, 그리고 문자가 세 개인 경우까지 차례로 보겠습니다.

## 2. 왜 필요한가

**슬라이드에 적을 것**

시험: 합·곱이 주어지고 → 제곱의 합, 세제곱의 합 값을 묻는다
문자의 값을 직접 구하지 않는다

**수지쌤이 말할 것**

시험에서는 엑스 더하기 와이와 엑스와이의 값을 주고, 엑스 제곱 더하기 와이 제곱이나 엑스 세제곱 더하기 와이 세제곱의 값을 묻습니다. 엑스 더하기 엑스분의 일을 주는 문제도 있고, 문자가 세 개인 문제도 나옵니다. 문자를 직접 구하면 계산이 복잡해지므로, 식을 바꿔서 합과 곱으로 푸는 것이 핵심입니다.

## 3. ① 두 문자의 합과 곱

**슬라이드에 적을 것**

$x^2+y^2=(x+y)^2-2xy$
$x^3+y^3=(x+y)^3-3xy(x+y)$
이유: 전개식에서 구할 항만 남기고 나머지를 넘긴 것

**수지쌤이 말할 것**

엑스 더하기 와이의 제곱을 전개하면 엑스 제곱 더하기 와이 제곱 더하기 이 엑스와이입니다. 그래서 엑스 제곱 더하기 와이 제곱은 엑스 더하기 와이의 제곱 빼기 이 엑스와이입니다. 세제곱도 같습니다. 엑스 더하기 와이의 세제곱을 전개한 식에서 곱이 들어간 항을 넘기면, 엑스 세제곱 더하기 와이 세제곱은 엑스 더하기 와이의 세제곱 빼기 삼 엑스와이 곱하기 엑스 더하기 와이가 됩니다. 외우기 전에 전개식에서 항을 옮긴 것이라고 이해하시면 됩니다.

## 4. ② $x+\frac{1}{x}$ 꼴

**슬라이드에 적을 것**

$x\cdot\frac{1}{x}=1$
$x^2+\frac{1}{x^2}=\left(x+\frac{1}{x}\right)^2-2$
$x^3+\frac{1}{x^3}=\left(x+\frac{1}{x}\right)^3-3\left(x+\frac{1}{x}\right)$

**수지쌤이 말할 것**

엑스 곱하기 엑스분의 일은 항상 일입니다. 그래서 앞 공식에서 곱 자리에 일을 넣으면 됩니다. 엑스 제곱 더하기 엑스 제곱분의 일은 엑스 더하기 엑스분의 일의 제곱 빼기 이입니다. 세제곱은 엑스 더하기 엑스분의 일의 세제곱 빼기 삼 곱하기 엑스 더하기 엑스분의 일입니다.

## 5. ③ 문자가 세 개일 때

**슬라이드에 적을 것**

$a^2+b^2+c^2=(a+b+c)^2-2(ab+bc+ca)$
$a^3+b^3+c^3-3abc=(a+b+c)(a^2+b^2+c^2-ab-bc-ca)$
필요한 값: $a+b+c$, $ab+bc+ca$, $abc$

**수지쌤이 말할 것**

에이 더하기 비 더하기 씨의 제곱을 전개하면 제곱항 외에 서로 곱한 항이 두 개씩 생깁니다. 그래서 에이 제곱 더하기 비 제곱 더하기 씨 제곱은 에이 더하기 비 더하기 씨의 제곱 빼기 이 곱하기 에이비 더하기 비씨 더하기 씨에이입니다. 세제곱의 합은 에이 세제곱 더하기 비 세제곱 더하기 씨 세제곱 빼기 삼 에이비씨가, 에이 더하기 비 더하기 씨 곱하기 에이 제곱 더하기 비 제곱 더하기 씨 제곱 빼기 에이비 빼기 비씨 빼기 씨에이와 같다는 식을 씁니다. 그래서 세 값, 합과 두 개씩 곱한 것의 합, 그리고 세 문자의 곱이 필요합니다.

## 6. 정리

**슬라이드에 적을 것**

외울 것: 합과 곱으로 바꾼다 → $(x+y)^2-2xy$
실수: 세제곱에서 $3xy(x+y)$ 의 3과 $(x+y)$ 빼먹기, $x-y$ 와 $x+y$ 부호 혼동

**수지쌤이 말할 것**

외울 것은 하나입니다. 제곱의 합은 합의 제곱에서 곱의 이 배를 뺀다는 것입니다. 자주 틀리는 부분은 세제곱 공식에서 삼과 엑스 더하기 와이를 곱하는 것을 빼먹는 경우, 그리고 합이 아니라 차가 주어졌을 때 부호를 헷갈리는 경우입니다. 식을 바꾼 뒤 값을 대입하기 전에 부호를 한 번 더 확인하세요.
