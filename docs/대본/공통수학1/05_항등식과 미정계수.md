## 1. 항등식과 미정계수

**슬라이드에 적을 것**

미정계수 구하기
· 계수 비교법
· 수치 대입법

**수지쌤이 말할 것**

이번 시간에는 항등식과 미정계수를 배웁니다. 항등식의 뜻을 알고, 계수 비교법과 수치 대입법으로 미정계수를 구해 보겠습니다.

## 2. 왜 필요한가

**슬라이드에 적을 것**

$a(x+1)+b(x-1)=3x+5$ 가 $x$에 대한 항등식일 때, $a,\ b$의 값은?
→ 계수 비교법 또는 수치 대입법

**수지쌤이 말할 것**

시험에서는 어떤 등식이 x에 대한 항등식일 때 문자 a, b의 값을 구하라고 묻습니다. 항등식이라는 조건을 보고 계수 비교법이나 수치 대입법 중 알맞은 방법을 골라 푸는지를 확인하는 것입니다. 두 방법을 모두 할 줄 알아야 합니다.

## 3. 항등식이란

**슬라이드에 적을 것**

항등식: $x$에 어떤 값을 넣어도 항상 성립하는 등식
$ax^2+bx+c=0$ 이 항등식 $\Leftrightarrow a=b=c=0$
$ax^2+bx+c=a'x^2+b'x+c'$ 이 항등식 $\Leftrightarrow a=a',\ b=b',\ c=c'$

**수지쌤이 말할 것**

항등식은 문자에 어떤 값을 넣어도 항상 성립하는 등식입니다. 방정식은 특정한 x 값에서만 성립하지만, 항등식은 모든 x에서 성립합니다. 모든 x에서 같은 값이 나오려면 두 다항식이 차수별로 똑같은 모양이어야 합니다. 그래서 에이 엑스 제곱 더하기 비 엑스 더하기 씨가 0에 대한 항등식이면 에이, 비, 씨가 모두 0입니다. 양변이 서로 항등식이면 같은 차수의 계수끼리 같습니다.

## 4. 계수 비교법

**슬라이드에 적을 것**

양변을 $x$에 대해 정리 → 같은 차수의 계수끼리 비교
$a(x+1)+b(x-1)=(a+b)x+(a-b)$
$a+b=3,\ a-b=5$
$\therefore a=4,\ b=-1$

**수지쌤이 말할 것**

계수 비교법은 양변을 전개해서 x의 차수별로 정리한 뒤, 계수끼리 같다고 놓는 방법입니다. 예를 들어 좌변을 정리하면 에이 더하기 비 곱하기 엑스, 더하기 에이 빼기 비가 됩니다. 우변 삼 엑스 더하기 오와 비교하면, x의 계수에서 에이 더하기 비는 3, 상수항에서 에이 빼기 비는 5입니다. 연립하면 에이는 4, 비는 마이너스 1입니다.

## 5. 수치 대입법

**슬라이드에 적을 것**

$x$에 편한 값을 대입
$x=1$: $2a=8,\ a=4$
$x=-1$: $-2b=2,\ b=-1$
※ 괄호 안이 $0$이 되는 값을 고른다

**수지쌤이 말할 것**

수치 대입법은 항등식이 모든 x에서 성립하니, x에 편한 값을 직접 넣는 방법입니다. 같은 식에서 x에 1을 넣으면 b가 곱해진 항이 0이 되어 2a는 8, 에이는 4입니다. x에 마이너스 1을 넣으면 a가 곱해진 항이 0이 되어 마이너스 2b는 2, 비는 마이너스 1입니다. 괄호 안이 0이 되는 값을 고르면 계산이 쉽습니다. 다만 구할 문자의 개수만큼 값을 넣어야 합니다.

## 6. 정리

**슬라이드에 적을 것**

외울 것: 항등식 → 같은 차수의 계수끼리 같다 / 어떤 $x$를 넣어도 성립
실수 주의: ① 정리하지 않고 비교 ② 없는 차수의 계수는 $0$ ③ 값을 하나만 대입

**수지쌤이 말할 것**

외울 것은 항등식이면 양변의 같은 차수 계수가 같고, 어떤 x를 넣어도 성립한다는 점입니다. 흔한 실수는 양변을 정리하지 않고 계수를 비교하는 것, 식에 없는 차수의 계수를 0으로 보지 않는 것입니다. 또 수치 대입에서 문자가 둘인데 값을 하나만 넣고 끝내는 실수도 많으니 조심하세요.
