# 17. 고차방정식의 풀이

## 1. 고차방정식의 풀이

**슬라이드에 적을 것**

삼차·사차방정식
→ 일차식·이차식의 곱으로 쪼개기

**수지쌤이 말할 것**

이번 시간에는 고차방정식의 풀이를 배웁니다. 삼차, 사차처럼 차수가 높은 방정식을 일차식이나 이차식의 곱으로 쪼개서 푸는 방법입니다.

## 2. 왜 필요한가

**슬라이드에 적을 것**

차수가 높다 → 바로 풀기 어렵다
→ 풀 수 있는 모양으로 바꾼다
시험: 삼차·사차방정식의 근 구하기

**수지쌤이 말할 것**

차수가 높은 방정식은 이차방정식처럼 곧바로 풀 수 없습니다. 그래서 풀 수 있는 모양으로 바꾸는 것이 핵심입니다. 시험에서는 삼차나 사차방정식의 근을 직접 구하라고 묻습니다. 앞에서 배운 곱셈 공식과 다항식의 나눗셈이 그대로 도구가 됩니다.

## 3. 방법 1. 인수분해

**슬라이드에 적을 것**

$A\cdot B=0 \iff A=0$ 또는 $B=0$
$a^3-b^3=(a-b)(a^2+ab+b^2)$
예) $x^3-8=0$
$(x-2)(x^2+2x+4)=0$
$x=2$ 또는 $x=-1\pm\sqrt{3}i$

**수지쌤이 말할 것**

가장 기본은 인수분해입니다. 식을 곱의 꼴로 바꾸면, 곱이 영이니까 각 인수가 영인 경우를 따로 풀면 됩니다. 예를 들어 엑스 세제곱 빼기 팔은 곱셈 공식으로 엑스 빼기 이 곱하기 엑스 제곱 더하기 이 엑스 더하기 사로 나뉩니다. 그러면 엑스는 이이거나, 이차방정식 엑스 제곱 더하기 이 엑스 더하기 사가 영인 근, 즉 마이너스 일 플러스 마이너스 루트 삼 아이입니다.

## 4. 방법 2. 인수정리와 조립제법

**슬라이드에 적을 것**

$P(\alpha)=0 \Rightarrow (x-\alpha)$ 는 $P(x)$의 인수
후보: (상수항의 약수) ÷ (최고차항 계수의 약수)
예) $x^3-2x^2-5x+6=0$
$P(1)=0$ → $(x-1)(x^2-x-6)=0$
$(x-1)(x-3)(x+2)=0$
$x=1,\ 3,\ -2$

**수지쌤이 말할 것**

공식이 안 보이면 인수정리를 씁니다. 피 알파가 영이면 나눈 나머지가 영이라서, 엑스 빼기 알파로 딱 나누어떨어지기 때문입니다. 알파는 상수항의 약수 중에서 대입해 봅니다. 위 식에 일을 넣으면 영이 되므로 엑스 빼기 일이 인수입니다. 조립제법으로 나누면 몫이 엑스 제곱 빼기 엑스 빼기 육이고, 이것을 다시 인수분해하면 근은 일, 삼, 마이너스 이입니다.

## 5. 방법 3. 치환

**슬라이드에 적을 것**

공통부분 또는 $x^2$ 을 $t$ 로 치환
예) $x^4-5x^2+4=0$
$x^2=t$ → $t^2-5t+4=0$
$(t-1)(t-4)=0$
$x^2=1$ 또는 $x^2=4$
$x=\pm1,\ \pm2$

**수지쌤이 말할 것**

사차방정식에 엑스 사제곱과 엑스 제곱만 있으면 엑스 제곱을 티로 놓습니다. 그러면 티에 대한 이차방정식이 되어 쉽게 풀 수 있기 때문입니다. 티 빼기 일, 티 빼기 사가 영이니 티는 일 또는 사입니다. 그다음 엑스 제곱이 일 또는 사인 경우로 돌아가 엑스를 구하면 플러스 마이너스 일, 플러스 마이너스 이입니다.

## 6. 정리

**슬라이드에 적을 것**

외울 것: 곱으로 쪼갠 뒤 각 인수 $=0$
실수: 근 하나만 찾고 멈춤 / 치환 후 $t$ 에서 멈춤 / $x-\alpha$ 부호

**수지쌤이 말할 것**

외울 것은 하나입니다. 곱의 꼴로 쪼갠 뒤 각 인수를 영으로 놓고 푼다. 흔한 실수는 세 가지입니다. 근을 하나 찾고 멈추는 것, 치환했을 때 티 값만 구하고 엑스로 돌아가지 않는 것, 그리고 알파가 마이너스 일일 때 인수를 엑스 빼기 일로 쓰는 부호 실수입니다.
