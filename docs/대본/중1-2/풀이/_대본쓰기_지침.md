## 쎈이 다른 점
- **교재 풀이가 없다.** 쎈 해설집은 스캔본이라 잘라 둔 풀이 그림이 없다 → 문제를 직접 정확히 풀고, 답이 `answer` 와 **반드시** 같아야 한다.
  다르면 문제를 다시 읽고, 그래도 다르면 대본을 쓰지 말고 보고한다(정답이 틀렸을 수도 있다).
  필요하면 해설집 스캔본을 볼 수 있다: `C:/Users/USER/Desktop/빅픽쳐/문제은행/중등/중1/２학기/유형서/쎈/쎈 중1-2 [2022개정] 해설.pdf` (120쪽, 번호는 주황 4자리 「0060」. 쪽 번호 ≈ 문항 번호 비례로 짐작해 PyMuPDF 로 그 쪽을 그림으로 떠서 Read).
- **중학생이 본다.** 그 학년에서 배운 말과 방법만 쓴다(중1 은 문자와 식·방정식까지, 중1-2 는 도형·통계). 고등 개념·공식 이름을 쓰지 않는다.
- 이 영상은 **유형의 대표문제**다. 마지막 정리에서 「이 유형은 이렇게 푼다」를 한 문장으로 짚는다(같은 유형 문제를 혼자 풀 수 있게).
- 객관식(①~⑤)이면 보기를 하나씩 따지는 문제는 틀린 보기가 왜 틀렸는지 짧게, 답 보기는 분명하게. 계산형 객관식은 값을 구하고 그 값이 몇 번인지 말한다. 노트에 보기 번호 ①②③④⑤ 는 손글씨 글꼴에 없어 □ 로 깨진다 → `$①$` 처럼 수식 안에 넣는다(대신 쓸 글꼴로 그려진다).
- 문제 그림이 길면(세로가 가로보다 길면) 화면 위에서 너무 작아진다 → problem crop 으로 문제 글·그림만 남기고, 보기는 첫 단계 노트에 짧게 quiet 로 적는다.
- 도형 문제는 문제 그림이 화면 위에 계속 보이니 「그림에서 …」로 가리키며 설명한다. 그림이 더 필요하면 문제 그림 일부를 figure 로 붙일 수 있다(`{"image": "<local_no>.png", "crop": [..]}`).
