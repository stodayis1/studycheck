## 그림이 있는 문제 — 그림판에서 짚으며 푼다 (원장님 2026-11-06, 가장 중요)
원장님: 「말로만 설명하면 집중도 덜 되고 이해도 힘들다. 꼭짓점을 가리킬 땐 꼭짓점을, 모서리·직선도 마찬가지로 짚어야 한다. 보조선은 그림에 직접 표기해야 한다.」
- 문제에 그림(도형·그래프·표)이 있으면 **반드시** `"board"` 를 쓴다. 형식은 `scripts/lesson-video/board.py` 맨 위 설명.
  - `"problem": {"image": "<no>.png", "crop": [글·보기 부분]}` + `"board": {"image": "<no>.png", "crop": [그림 부분]}` — 문제 그림 하나를 둘로 나눈다(그림은 노트 오른쪽에 크게 뜬다)
- **말에서 도형의 부분을 부르면 그 순간 그 부분을 짚는다** — 단계마다 `"marks"`, cue 는 그 말 글자:
  - 「꼭짓점 에이」「점 씨」 → point · 「선분 에이비」「모서리」 → seg (여러 개 이어지면 path) · 「직선 엘」 → line · 「반직선」 → ray
  - 「각 비」「각 엑스」 → angle (pts = [한 변 쪽 점, 꼭짓점, 다른 변 쪽 점]) · 「삼각형 에이비씨」 → poly · 원 → circle
  - 구한 값(「삼십오 도」)은 label 로 그림에 적고 `keep: true` — 다음 단계에서 그 값을 쓰니까
  - **보조선**(풀이에 필요한 선을 새로 긋는 문제)은 aux 로 긋는다. 말로 「여기 보조선을 그어 보자」 하면서. 보조선이 만든 새 점은 label 로 이름을 붙인다
  - 세는 문제(꼭짓점·모서리·직선 개수)는 「하나, 둘, 셋…」 하며 하나씩 point/seg 를 찍고 번호 label 을 붙인다 (본보기: 0060)
  - 본보기: `풀이_0535_…json`(각·이등변삼각형·외각), `풀이_0060_…json`(세기)
- 좌표 읽기: `python scripts/lesson-video/board_grid.py R/<no>.png <스크래치>/g.png --crop <그림 부분> --step 10` → 그림을 Read 해서 꼭짓점 좌표(원본 픽셀)를 읽는다.
- 확인: proof_validate --sheet 가 `<id>_그림판.png` 를 만든다 — **표시가 꼭짓점·선에 정확히 붙었는지 꼭 열어 본다.** 어긋나면 좌표를 고친다.
- cue 는 말 안에 있어야 하고, 같은 단계에서 같은 낱말이 앞에 또 나오면 앞의 것에 붙는다(세는 말 「하나」 앞에 「하나씩」을 쓰지 않기).
