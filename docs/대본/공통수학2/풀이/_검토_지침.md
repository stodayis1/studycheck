편마다 할 일:
1. 문제를 **처음부터 혼자** 풀어 답을 낸다. 교재 풀이와 대본의 답이 모두 같은지.
2. 노트 tex 줄을 하나하나 검산(전개·부호·분수·근호·좌표·괄호·부등호 방향·집합 원소·참거짓 판정). 문제의 숫자·조건과 같은지.
3. say 에서 소리 내 읽는 수식·숫자·답이 tex 와 같은 내용인지. 개념 설명이 수학적으로 맞는지(명제·집합은 특히 말 한 마디가 뜻을 바꾼다 — 「충분」/「필요」, 「또는」/「그리고」, 부정 등).
4. **들리는 소리**: 숫자 뒤 조사 「이」 때문에 다른 수로 들리는 곳(「십이 나오죠」=12처럼)을 찾아 고친다.
5. problem crop / figure crop 이 있으면 PIL 로 잘라 스크래치 폴더에 저장해 Read 로 보고, 필요한 부분이 다 들어가고 다른 문제가 섞이지 않았는지.
6. 틀린 것이 있으면 **그 파일을 직접 고친다**(최소한으로, Write/Edit 도구 — Bash heredoc 은 역슬래시를 망가뜨린다). 고친 뒤 `PYTHONIOENCODING=utf-8 python scripts/lesson-video/proof_validate.py <파일> --sheet <스크래치>` 이 고칠 것 0, 경고 0 인지, 미리보기에서 고친 줄이 제대로 그려지는지 확인.
