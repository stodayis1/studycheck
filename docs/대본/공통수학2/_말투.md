## 문장 끝
- 기본은 **반말**: 「~하면 돼」, 「~되는 거야」, 「~되는 거다」, 「~해야 돼」, 「~볼게」
- 학생에게 확인할 때는 **「~죠?」, 「~겠죠」**: 「기억나죠?」, 「선분 AB가 생기죠」, 「사가 되겠죠」
- 질문은 반말: 「어떻게 구할까?」, 「얼마가 될까?」, 「어떻게 해야 돼?」
- 정리할 때는 「~되는 거다」로 딱 끊는다
- 「~합니다」, 「~해요」는 거의 안 쓴다. 쓴다면 마무리 인사 정도(「다음 시간에 만납시다」)

## 입버릇
- 문단 시작마다 **「자,」**: 「자, 개념 설명을 먼저 하면」, 「자, 이번에는」
- 이어 갈 때는 「그래서」, 「그러면」, 「그다음」
- 강조할 때: 「여기가 진짜 많이 틀려」, 「별표 빡 쳐 놓고」, 「진짜 조심해야 돼」, 「아주 열심히 기억해 놔야 돼」
- 칭찬할 때: 「오케이, 잘했어」

## 수식 읽기 (원장님 식)
- 아래첨자는 영어 숫자로 읽는다: x₁ = 「엑스 원」, x₂ = 「엑스 투」
- ± = 「플마」 (처음 한 번은 「플러스 마이너스」)
- 반지름 r = 「알」, f(x) = 「에프 엑스」, f(3) = 「에프 삼」
- 좌표 (1, 2) = 「일 콤마 이」
- 더하기/플러스, 빼기/마이너스는 섞어 쓴다. 대본에서는 식 안에서는 「더하기·빼기」, 부호는 「마이너스」로 통일
- 문자는 반드시 한글로 쓴다(에이, 비, 엑스, 와이). 대본에 영문자나 기호가 남으면 음성이 이상하게 읽는다

# 풀이 영상(필수예제) — 추가 규칙 (원장님 2026-10-20)

## 숫자를 다 읽지 않는다
- 증명이 아니다. **식 세우는 한 줄과 답만 소리 내어 읽고**, 전개·인수분해·이항 같은 계산은 화면에만 쓴다.
- 대본에서는 말 안에 `[[쓰기]]`를 넣고, 그 자리에서 쓸 줄에 `"quiet": true`를 붙인다. 말이 멈춘 동안 그 줄들이 차례로 써진다.
  - 예: 「자, 양변을 제곱하면 이차방정식이 나와. / 풀어 보면 [[쓰기]] 에이는 마이너스 일 또는 칠이 되는 거다.」
- 소리 내어 읽는 것: 문제의 조건, 어떤 공식을 쓰는지, 식의 **첫 줄**(왜 이 식인지), 계산에서 **주의할 한 군데**, 답
- 읽지 않는 것: 전개한 각 항, 이항한 결과, 인수분해 과정, 근의 공식 대입

## 말투 버전 — 편마다 돌려 쓴다
같은 말이 매번 나오면 지루하다. 아래 묶음에서 **편 번호마다 다른 것**을 고르고, 바로 앞 편과 같은 말은 피한다.

**시작**
1. 「자, 필수예제 ○번 같이 풀어 보자.」
2. 「오늘 볼 문제는 이거야. 문제부터 천천히 읽어 볼게.」
3. 「자, 이 문제 시험에 진짜 잘 나와. 같이 보자.」
4. 「자, 이번 문제는 개념만 알면 금방 풀려.」
5. 「자, 문제 먼저 보자. 뭘 구하라는 건지부터 찾아 봐.」

**먼저 풀어 보게 하기**
1. 「자, 여기서 잠깐. 영상 멈추고 먼저 혼자 풀어 봐.」
2. 「바로 보지 말고 일단 네가 먼저 풀어 봐. 다 풀면 다시 틀어.」
3. 「손으로 먼저 풀어 보고 와. 기다릴게.」
4. 「일 분만 고민해 봐. 막히면 그때 다시 틀어도 돼.」
5. 「연필 들었지? 먼저 풀고 답 맞춰 보자.」

**계산은 보여만 줄 때**
1. 「풀어 보면」 / 「정리하면」 / 「쭉 계산하면」 / 「인수분해하면 바로 나와」
2. 「이건 이차방정식이니까 풀기만 하면 돼.」
3. 「계산은 화면 보면서 따라와.」
4. 「여기는 어렵지 않으니까 쭉 써 볼게.」

**답 말하기**
1. 「그래서 답은 ○○이 되는 거다.」
2. 「답은 ○○. 맞았어?」
3. 「○○ 나왔죠? 오케이.」
4. 「그러면 ○○, 이게 답이야.」

**주의 짚기**

2. 「별표 빡 쳐 놔.」
3. 「이거 하나만 조심하면 돼.」

**마무리**

## 끊김·로봇 같은 억양 줄이기 (원장님 2026-10-20: 「맞았어?」가 로봇 같고, 끊기는 구간이 AI 티 난다)
소리는 `/`, `//`, `{강조 …}` 마다 **토막으로 따로** 받아 이어 붙인다. 토막이 짧을수록 억양이 기계처럼 된다.
- **한 토막은 한 구절 이상(8자 이상).** 「맞았어?」, 「답은」, 「여기 봐.」를 혼자 두지 않는다.
  - ✗ 「답은 / {강조 에이는 일.} / 맞았어?」 → ✓ 「{강조 에이는 일이 나오는 거야.} 너도 맞았지?」
- **{강조}는 꼬리말까지 감싼다.** ✗ 「{강조 에이는 일}이 되는 거다」 → ✓ 「{강조 에이는 일이 되는 거다.}」
- **`/`는 숨 쉬는 자리에만.** 한 문장 안에서는 거의 안 쓴다. 문장 사이는 `//`.
- **[[쓰기]] 앞뒤는 완결된 문장으로.** 문장 중간에서 끊고 쓰면 말이 멈췄다가 어색하게 이어진다.
  - ✗ 「쭉 풀어 보면 [[쓰기]] 인수분해까지 하면 바로 나와.」
  - ✓ 「양변을 제곱해서 쭉 정리해 볼게. [[쓰기]] 인수분해까지 하면 답이 바로 나오죠.」
- 「자, 이번.」처럼 짧은 시작 말은 다음 문장과 붙인다: 「자, 이번에는 이번 문제 보자.」
- 검사기(`proof_validate.py`)가 짧은 토막과 문장 중간 [[쓰기]]를 경고로 알려 준다 — 경고 0개로 맞춘다.
