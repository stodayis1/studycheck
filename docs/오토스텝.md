# 오토스텝 — 진도를 체크하면 유형편 숙제가 따라 나온다

학습일지(`app/teacher/learning-notes`) 진도탭에서 **개념을 체크하는 즉시**, 그 개념에 해당하는
**유형편 쪽수**를 찾아 ① 그 자리 과제배부 칸에 제안으로 띄우고 ② 학습지관리 「병행교재」 탭에
알림으로 쌓는다. 선생님이 「확인」을 눌러 과제로 낸다 — **진도 체크만으로 과제가 저절로
배정되지는 않는다**(일부러 그렇게 뒀다. 쪽수가 늘 맞는지 사람이 한 번 본다).

## 누구에게 도는가 — `lib/autostep.ts` 한 곳

| 길 | 무엇 |
|---|---|
| `AUTOSTEP_OPEN_SEMESTERS` | **그 교재를 쓰는 학생 모두**에게 열린 교재·학년·학기. 지금은 `개념유형 중1-2` (원장님 2026-11-16 「개념유형 중1-2 교재 쓰는 학생들에게는 모두 적용해줘」) |
| `AUTOSTEP_PILOT_STUDENT_IDS` | 한 명씩 늘려 가며 보던 파일럿 학생. 교재·학기를 가리지 않는다 |
| `AUTOSTEP_TEXTBOOK_NAMES` | 쪽수 매핑을 만들어 둔 개념서 이름(`개념+유형라이트`, 옛 이름 `개념유형 라이트`). 개념리피트처럼 매핑 없는 개념서엔 뜨면 안 된다 |

★ **교재 배정 화면과 학습일지 화면이 같은 판단을 써야 한다.** 예전에는 파일럿 명단이 두 파일에
베껴 적혀 있었다 — 한쪽만 고치면 배정 화면엔 스텝 고르기가 뜨는데 학습일지에선 알림이 안 생기고,
**에러도 안 난다.** 그래서 판단을 `lib/autostep.ts` 한 곳에 두고 양쪽이 불러 쓴다.

## 학기를 더 열 때 — 쪽수 매핑을 먼저 센다

`autostep_concept_page_map` 에 그 학기 개념이 **전부** 들어가 있어야 한다. 비어 있으면 알림이
조용히 안 생긴다(에러가 없다).

```sql
select c.grade, c.semester, count(*) 개념, count(m.concept_id) 매핑
  from concepts c left join autostep_concept_page_map m on m.concept_id = c.id
 group by 1,2 order by 1,2;
```

2026-11-16 기준 전수 매핑: **중1-1(60) · 중1-2(48) · 중2-1(58) · 중2-2(52) · 중3-1(58)**.
중3-2(0/32) · 초등 전 학년 · 고등은 **0건** — 여기를 열면 아무 일도 안 일어난다.

세는 순서: ① 위 쿼리로 매핑 확인 ② `AUTOSTEP_OPEN_SEMESTERS` 에 한 줄 추가
③ `scripts/autostep-check.ts` 의 `매핑된학기` 도 같이 고친다 ④ 검사를 돌린다.

```
node --import ./scripts/ts-resolve.mjs scripts/autostep-check.ts
```

「오토스텝 자가확인 ✓」가 나와야 한다. 매핑이 없는 학기를 열면 **이 검사가 막는다.**

## 표

| 표 | 무엇 |
|---|---|
| `autostep_concept_page_map` | 개념 하나 → 개념편·유형편 쪽수 |
| `autostep_workbook_map` | 소단원 → 단원마무리 쪽수(대단원 마지막 소단원일 때만) |
| `autostep_homework_alerts` | 쌓인 알림. `acknowledged_at` 이 비어 있는 것만 화면에 뜬다. 같은 학생+개념은 유니크 제약으로 한 번만 |
| `student_textbooks.autostep_level` | 하루 진도량(1~3스텝). **완료 예상일을 보여 주는 값일 뿐** 알림 생성에는 쓰이지 않는다 |

쎈B(유형서)는 쪽수가 아니라 **문제 번호**로 나간다 — `lib/ssenbSteps.ts`, `ssenb_problem_map`,
`student_textbooks.ssenb_step`(1~4). 이쪽은 아직 파일럿 학생만이다.
