# 매쓰홀릭 붙여넣기 규칙 고치기

원장님이 매쓰홀릭 학습지 제목·종류 규칙을 말씀하시면(「월간평가는 코어테스트로 올리면됨」,
「레벨 없고 00회차는 이너프원이야」) **네 곳**을 같이 고친다. 한 곳만 고치면 조용히 어긋난다.

## 고칠 곳 (순서대로)

| 순서 | 파일 | 무엇 |
|---|---|---|
| ① | `lib/matholic.ts` | 판정 함수 — 여기가 유일한 규칙 자리 |
| ② | `app/teacher/assignments/matholic/page.tsx` | 그 판정을 **실제로 쓰는** 곳 (읽기 + 저장) |
| ③ | `scripts/matholic-check.ts` | 새 규칙마다 검사 한 줄 |
| ④ | `app/teacher/manual/page.tsx` | 선생님이 읽는 안내 — 제목 쓰는 법이 바뀌면 반드시 |

①만 고치고 ②를 안 고치는 실수가 가장 많다. 함수는 고쳤는데 화면이 안 부르면
**에러가 안 나고** 규칙이 없는 것과 똑같다. 고친 함수의 이름으로 `grep` 해서
부르는 자리를 눈으로 확인한다.

## 판정 함수 지도 (`lib/matholic.ts`)

- `coreTestRound(row)` → 평가관리로 보낼 것인가, 몇 회차인가
- `isEnoughOne(row)` → 아예 안 넣을 것인가 (이너프원)
- `isDailyTest(row)` → 학습일지 데일리테스트 칸
- `isWrongNote(row)` → 오답 학습지인가
- `worksheetTypeOf(row)` → `main`(레벨) · `similar`(오답) · `twin`(쌍둥이)
- `needsLevel(row)` → 레벨이 없으면 막을 것인가
- `prevLevelOf(list, date)` → 오답이 물려받을 직전 레벨
- `wrongNoteFix(unitName, level, prevMainLevel)` → 오답 제목·레벨

규칙 표는 `KINDS` 바로 위 큰 주석에 있다. **거기에 날짜와 원장님 말씀을 그대로** 적는다 —
한 달 뒤에 「왜 이렇게 했지」를 코드만 보고는 알 수 없다.

## 검사

```
node --import ./scripts/ts-resolve.mjs scripts/matholic-check.ts
```

`npx tsx` 는 **안 된다** (top-level await → cjs 오류). 위 명령만 쓴다.

마지막 줄 「통과 N / 전체 N」이 같아야 통과. 그리고 **반드시 망가뜨려 시험한다** —
일부러 틀린 사본을 만들어 같은 명령에 경로로 넘기고, 새로 넣은 검사가 **실패하는지** 본다.

```
node --import ./scripts/ts-resolve.mjs scripts/matholic-check.ts <틀린사본.ts>
```

실패하지 않으면 검사가 없는 것이다.

## 함정 (실제로 당한 것)

1. **판정 순서.** 매쓰홀릭은 TOMA 건에도 종류를 「월간평가」로 붙여 준다.
   월간평가를 먼저 보면 TOMA 본고사가 「월간평가」로 밀린다 (2026-11-02, 검사가 잡았다).
   새 낱말을 넣을 때는 **이미 있는 낱말과 겹치지 않는지** 먼저 본다.
2. **`needsLevel` 이 막아 버린다.** 레벨을 물려받게 만든 종류(오답)는 `needsLevel` 에서도
   빼야 한다. 안 빼면 그 줄이 통째로 「레벨이 없어요」로 막히고, 화면은 멀쩡해 보인다.
3. **`strictNullChecks` 가 꺼져 있다.** `{ok:true}|{ok:false}` 꼴 유니온은 좁혀지지 않는다.
4. **Bash heredoc 은 역슬래시를 한 겹 먹는다.** 정규식이 든 패치 스크립트는 Bash heredoc
   말고 **Write 도구로 파일을 만들어** 돌린다 (`python -I <경로>`).
5. **점수가 두 군데 생기는 것.** 데일리테스트를 학습지로도 넣으면 성취도·브리핑이 두 번 센다.
   새 종류를 만들 때 「이 점수가 이미 다른 칸에 들어가지 않나」를 먼저 본다.
6. **이름이 아니라 레벨이 열쇠인 규칙이 있다.** 「레벨이 없고 N회차」처럼 **없는 것**으로
   가르는 규칙은 `row.level` 을 함수에 넘겨야 한다 — 넘기는 자리를 빼먹으면 늘 false 다.

## 범주를 지어내지 않는다

원장님 2026-10-31 「규칙을 너무 많이 만들면 되려 헷갈려. 현재 쓰고 있는 규칙에서 우리가
범주를 만들어가는게 맞아」.

새 범주가 필요해 보이면 **선생님들이 이미 손으로 적고 있는 말을 세어** 본다.

```sql
select worksheet_unit, count(*) from learning_notes
where worksheet_unit is not null and worksheet_unit <> ''
group by 1 order by 2 desc;
```

2026-10-31 에 세어 보니 154건 중 과제 44 · 오답 20 · 레벨/Lv 22 · 이너프원 2 ·
낱말 없이 단원명만 65 였고, 내가 표에 넣었던 수행평가·교과서·주간/월간평가는 **0건**이었다.

- `npx next build` 까지 돌린다 (`ignoreBuildErrors` 가 켜져 있으니 **내가 만든 에러인지**
  `git diff` 로 가른다).
