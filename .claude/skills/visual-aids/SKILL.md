# 수업 시각화 — 입체·공간 단원 3D 자료

## 목적

말로 설명하기 힘든 공간·입체 단원(쌓기나무, 회전체, 전개도, 꼬인 위치 …)을 선생님이 수업 화면(TV·태블릿)에
띄워 **돌려 보고, 펴 보고, 잘라 보게** 하는 자료다. 학생 데이터는 전혀 쓰지 않는다.

- 자료: `public/visual/<이름>.html` — 한 장짜리 HTML(three.js r128). 로그인 없이 `/visual/<이름>.html` 로 열린다.
- 목록: `app/teacher/visual-aids/page.tsx` 의 `STAGES` (학년 순: 초등 → 중1-2 → 중2 → 고등). 카드를 누르면 새 탭.
- 메뉴: `components/teacher/Sidebar.tsx` 의 `ITEM.visualAids` — 「수업」 묶음, 모든 선생님에게 보인다.
- 매뉴얼: `app/teacher/manual/page.tsx` 의 `/teacher/visual-aids` 항목 (자료 수·목록을 notes 에 적어 둠).
- 캐릭터: `public/visual/suji.png` (풍선 든 수지, `public/logo.png` 를 잘라 240px 로 줄인 것 · 40KB).
- 원장님 계정의 claude.ai 아티팩트(쌓기나무·회전체 첫 판)는 **옛 판**이다. 고칠 때는 `public/visual` 만 고친다.

## 페이지 꼴 (새 자료는 `hoijeon.html` 을 틀로 그대로 따른다)

- 맨 위: `<!doctype html><html lang="ko"><head>` + charset·viewport + `<style>body{margin:0}[hidden]{display:none!important}</style>`.
- 색: `:root` 밝은 토큰 한 벌만(수학의지혜 파랑 `#2563eb` · 주황 `#f26b1d`, 바탕 `#f4f9ff`). **어두운 모드 블록은 넣지 않는다**
  (원장님 2026-10-27 "색을 더 밝게" — 어두운 화면에서 칙칙해 보였다).
- 머리: `.brand` — `/visual/suji.png` + 「수학의지혜」(주황) + 「Wise Way to Win」(파랑), 그 아래 학년·단원 eyebrow, 제목, 한두 줄 설명.
- 글꼴: Google Fonts Gowun Batang(제목)·Gowun Dodum(본문). 외부 스크립트는 `cdnjs.cloudflare.com/ajax/libs/three.js/r128/three.min.js` 하나만.
- 3D 조작은 쌓기나무·회전체와 똑같이: 끌어서 돌리기, 휠·두 손가락 확대, 화살표 키, 「비스듬히/앞에서/위에서」 칩, ＋/－.
  `prefers-reduced-motion` 이면 움직임을 바로 끝 상태로.
- 글은 선생님이 읽는 말투(「~해요」), 교과서 용어 그대로. 휴대폰 폭(375px)에서 가로로 밀리면 안 된다.
- 처음 열었을 때 이미 뭔가 보이는 상태(예제 하나가 골라져 있는 상태)로 시작한다.

## 새 자료를 만들 때

1. 작업 폴더가 지금 어느 브랜치인지 먼저 본다(`git branch --show-current`). 다른 대화가 같은 폴더를 다른 브랜치로
   바꿔 쓰고 있을 수 있다 → 그럴 때는 **`origin/main` 에서 새 브랜치로 따로 worktree 를 펴서** 그 안에서 작업한다.
2. `public/visual/<영문이름>.html` 을 만든다 (위 꼴). 계산이 들어가는 함수는 **node 로 따로 돌려 값을 맞춘다**
   (공식 값과 화면 값이 같은지, 극단값·0·경계에서 깨지지 않는지).
3. 스크립트 문법: `node -e` 로 각 `<script>` 를 `new Function` 해 본다.
4. 브라우저 확인: 개발 서버(`.claude/launch.json` 의 `studycheck-dev`, localhost:3000)에서 `/visual/<이름>.html` 을 연다.
   - 내장 브라우저 탭은 **내가 만든 탭(tabs_create)만** 쓴다. 여러 작업이 같은 창을 나눠 쓴다.
   - `resize_window` 1280×900 으로 한 장, 375px 로 가로 밀림 확인, 콘솔 오류 확인, 주요 버튼 한 번씩. 끝나면 `preset: desktop` 으로 되돌린다.
5. 목록 `STAGES` 에 카드(`unit`·`what`·`href`)를 넣는다. 매뉴얼 notes 의 자료 수·목록도 고친다.
6. `npx tsc --noEmit` 에서 바꾼 파일에 오류가 없는지(원래 있던 오류와 구분).
7. 올리기 — AGENTS.md 「PR」 규칙대로 브랜치 push → PR 까지 만들고, 병합(=운영 배포)은 원장님이 하시거나 따로 허락하실 때만.
   병합 뒤에는 `curl` 로 `https://studycheck-five.vercel.app/visual/<이름>.html` 이 200 이고 새 글귀가 들어 있는지 확인한 뒤 「배포됐다」고 보고.

## 고칠 때 (선생님·원장님이 「부족하다」고 하신 것)

- 들은 말을 아래 「요청 기록」에 날짜와 함께 그대로 적고, 고친 뒤 무엇을 바꿨는지 한 줄 붙인다.
- 여러 자료에 다 해당하는 말(색, 글씨 크기, 버튼 위치, 머리 등)은 **12장 전부에** 같이 반영한다. 한 장만 고치고 끝내지 않는다.
  한꺼번에 바꿀 때는 `scripts` 없이 node 로 문자열을 바꾸되, 바꿀 글귀가 파일마다 몇 번 나오는지 세어 0번이면 멈춘다.
- 위 「페이지 꼴」이 바뀌면 이 문서의 꼴 설명도 같이 고친다.

## 함정

- **내장 브라우저는 claude.ai 아티팩트를 못 연다**(로그인 화면). 확인은 개발 서버의 `/visual/…` 로 한다.
- **내장 브라우저 창이 숨어 있으면 `requestAnimationFrame` 이 안 돈다** → 자바스크립트로 누르면 애니메이션 중간에 멈춘 것처럼 보인다.
  실제 클릭(computer left_click)으로 확인한다.
- Git Bash 에서 `git show origin/main:경로` 가 경로 변환으로 깨진다 → `MSYS_NO_PATHCONV=1` 을 붙인다.
- three.js `LatheGeometry` 로 꺾인 도형을 돌리면 모서리가 뭉개진다 → 꺾이는 꼭짓점은 점을 두 번 넣는다(회전체 `profile()`).
- `public/` 파일은 누구나 열 수 있다 — 학생 이름·성적 같은 것은 절대 넣지 않는다.
- 한 장에 three.js 를 쓰지 않아도 되는 것(도형 이동처럼 평면)은 SVG 로 가볍게.
