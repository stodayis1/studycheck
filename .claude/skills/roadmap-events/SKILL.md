# 학생부 로드맵 소식 — 행사 찾아 올리기

원장님 2026-11-07 「모든 사이트, 대학교 사이트, 진로진학 사이트 등을 뒤져서 각 계열로 도움이 될 만한
박람회, 컨퍼런스, 설명회 등의 정보를 지속적으로 업로드 … 이주일에 한 번 해당 학부모·학생에게 공유」

정한 것: **원장님 확인 후 발송** · 2주에 한 번 · 문자 + 개인 페이지(/r/<token>) · 질문지 낸 학생·학부모.
**이 스킬은 찾아서 「검토대기」로 올리는 데까지만 한다. 승인·발송은 원장님이 한다.**

## 1. 누구를 위해 찾나
- 대상: 예비고1(현 중3) · 예비고2(현 고1) · 그 위 고등학생. 사는 곳 **고양(삼송·원흥·지축)**.
- 계열 (lib/careerSurvey.ts CAREER_FIELDS 와 같은 말만 쓴다):
  인문 · 사회·법·행정 · 경영·경제 · 교육 · 자연과학 · 공학 · IT·소프트웨어·AI · 의약·보건 · 생명·농림·환경 · 예술·체육
  모든 계열에 맞으면(대입 박람회 등) **공통**.
- 먼저 학생들이 실제로 고른 계열을 센다 — 많이 고른 계열을 더 찾는다:
  ```sql
  select f, count(*) from career_surveys, jsonb_array_elements_text(answers->'field') f group by f order by 2 desc;
  ```

## 3. 올리는 규칙 (틀린 정보가 나가면 학원 신뢰에 바로 타격)
- **공식 안내 페이지를 직접 열어** 날짜·장소·대상·신청 방법을 확인한 것만 올린다. 검색 결과 요약·블로그·뉴스만 보고 올리지 않는다.
- 공식 주소(url)가 없으면 올리지 않는다. 날짜가 「추후 공지」면 올리지 않는다(다음 차례에 다시 본다).
- 기간: **오늘부터 10주 안**에 열리는 것. 신청 마감이 지났으면 올리지 않는다.
- 지역: 고양·서울·경기 북부 또는 온라인. 먼 곳은 전국 단위로 이름난 것(KAIST 캠프 등)만.
- 대상이 학생(중·고)이 아니면 올리지 않는다(교사 연수·대학생 대상 제외).
- `summary` 는 학부모님이 읽을 두세 줄 — 무엇을 하고 왜 도움이 되는지. 「무조건」「꼭 가야」 같은 말 금지.
- `source_note` 에 **확인한 페이지와 날짜**를 적는다: `2026-11-21 확인 — 입학처 공지 〈제목〉: 날짜·장소·대상·신청기간 대조`.
- 같은 행사(url+시작일)가 이미 있으면 넘어간다 — `on conflict (url, starts_on) do nothing`.
- 한 번에 많아야 20건. 계열이 한쪽에 쏠리지 않게.

## 4. 올리는 방법 (Supabase MCP, 프로젝트 cggskjxsyrvuhsldgkoj)
```sql
insert into career_events (title, host, kind, fields, grades, starts_on, ends_on, time_text, place, online,
  url, apply_url, apply_deadline, fee, summary, source_note, status, found_by)
values ('…', '…', '설명회', array['공학','IT·소프트웨어·AI'], array['중3','고1'], '2026-12-05', null, '오후 2시', '…', false,
  'https://…', 'https://…', '2026-11-30', '무료', '…', '2026-11-21 확인 — …', '검토대기', 'claude')
on conflict (url, starts_on) do nothing returning id, title;
```
- kind: 박람회 · 설명회 · 컨퍼런스 · 캠프 · 체험 · 특강 · 대회 · 기타
- grades 를 모르겠으면 빈 배열 `'{}'` (학년 무관).

## 5. 끝나면
